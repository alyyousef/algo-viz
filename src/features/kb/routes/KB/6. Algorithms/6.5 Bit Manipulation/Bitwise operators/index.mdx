While software engineers think in Base-10 (Decimal) and algebra, the CPU physically consists of microscopic transistors that only understand Base-2 (Binary). Bitwise operators are the exact mathematical gates used to manipulate those transistors.

## 1. The Logical Operators
These operators mathematically compare two integers bit-by-bit.
- **AND ( `&` )**: Returns 1 *only* if both bits are 1. (Used to mask/extract specific bits).
- **OR ( `|` )**: Returns 1 if *either* bit is 1. (Used to set/turn on specific bits).
- **XOR ( `^` )**: Returns 1 if the bits are *different*. (Used to toggle bits. Mathematically, `A ^ A = 0`, which is a powerful property for finding missing numbers).
- **NOT ( `~` )**: Inverts every single bit. (0 becomes 1, 1 becomes 0. In Two's Complement math, `~x = -x - 1`).

## 2. The Shift Operators
These operators physically move the bits left or right inside the CPU register.
- **Left Shift ( `<<` )**: Shifts all bits to the left, padding the right with zeroes. `(5 <&lt; 1)` mathematically shifts `0101` to `1010` (10). This is equivalent to multiplying by 2^N.
- **Right Shift ( `>>` )**: Shifts bits to the right. This is equivalent to integer division by 2^N. (Note: Java has both `>>` for Signed shift which preserves negative numbers, and `>>>` for Unsigned logical shift).
