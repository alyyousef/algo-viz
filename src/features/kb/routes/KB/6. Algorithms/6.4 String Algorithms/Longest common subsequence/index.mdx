A "Subsequence" is mathematically different from a "Substring". A substring must be perfectly contiguous (no gaps). A subsequence allows gaps, as long as the mathematical order remains intact.
For `"ABCDEF"` and `"ACEG"`, the Longest Common Subsequence is `"ACE"`.

## 1. The DNA Sequence Problem
LCS is heavily utilized in bioinformatics to mathematically compare two strands of DNA to find evolutionary similarities, and in software engineering to generate the `git diff` between two versions of a text file.

## 2. Dynamic Programming Solution
Finding the LCS via brute-force recursion results in an exponential O(2^N) time complexity.
It is standardly solved using a 2D Dynamic Programming matrix.
- If the characters at `A[i]` and `B[j]` match, the mathematical sequence length increases by 1: `DP[i][j] = 1 + DP[i-1][j-1]`.
- If they do not match, the algorithm mathematically inherits the best sequence found so far by checking the cell above it and the cell to its left: `DP[i][j] = Math.max(DP[i-1][j], DP[i][j-1])`.
This elegantly collapses the exponential problem into a polynomial **O(N * M)** time complexity, making it trivial to process files with thousands of lines.
