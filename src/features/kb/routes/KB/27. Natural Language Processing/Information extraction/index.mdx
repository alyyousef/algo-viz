**Information Extraction (IE)** is a broad field of Natural Language Processing (NLP) dedicated to automatically pulling structured, organized facts out of unstructured text (like news articles, medical journals, or legal contracts).

If you have 10 million Wikipedia articles, humans cannot possibly read them all to build a database of "Who is married to Whom." Information Extraction algorithms automate this process, scanning the text and outputting clean, database-ready rows of facts.

## The Core Tasks of IE

Information Extraction is usually broken down into a pipeline of smaller, highly specific sub-tasks:

### 1. Named Entity Recognition (NER)
The first step is identifying the "things" in the text. An NER algorithm scans a sentence and tags specific words as **Entities** (e.g., Person, Organization, Location, Date, Currency).
*   **Input:** "Tim Cook announced a new iPhone in California."
*   **Output:** `[Tim Cook: PERSON]`, `[iPhone: PRODUCT]`, `[California: LOCATION]`

### 2. Coreference Resolution
Texts rarely use a person's full name in every sentence. They use pronouns ("he," "she," "it"). Coreference resolution maps all those pronouns back to the original Entity found in step 1, ensuring no facts are missed just because the author used the word "he."

### 3. Relation Extraction
Once the entities are found, the system tries to determine how they are connected. It looks for predefined relationships (e.g., "CEO_OF", "BORN_IN", "ACQUIRED_BY").
*   **Input:** "Satya Nadella, the CEO of Microsoft..."
*   **Output:** `(Satya Nadella) --[CEO_OF]--> (Microsoft)`

### 4. Event Extraction
The most complex task. It tries to identify complex, multi-part events (like a corporate merger, a terrorist attack, or a biological process) and fill in specific "slots" (Who was the attacker? What was the weapon? Where did it happen?).

## How IE is Built

Historically, IE systems were built using incredibly complex, manually written rule sets (e.g., "If you see a capitalized word, followed by 'Inc.', it is an Organization"). This was the basis of famous systems like Stanford CoreNLP.

Later, researchers used traditional machine learning (like Conditional Random Fields or Support Vector Machines) to train statistical models on hand-labeled datasets.

<Callout icon="brain" title="IE in the era of Generative AI">
Today, Large Language Models (LLMs) like GPT-4 have completely revolutionized Information Extraction. Instead of building a complex 4-step pipeline of distinct models, you can simply pass a raw PDF into an LLM and prompt it: *"Extract all the companies mentioned in this document, their CEOs, and their revenue. Return the result strictly as a JSON array."* The LLM performs NER, Coreference Resolution, and Relation Extraction implicitly in a single forward pass.
</Callout>
