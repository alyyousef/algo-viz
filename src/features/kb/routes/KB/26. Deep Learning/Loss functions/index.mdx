A Neural Network is essentially a massive mathematical function. But to train it, you must be able to mathematically quantify exactly how "bad" its current predictions are. This single number is generated by the **Loss Function** (or Objective Function).

## 1. Regression: Mean Squared Error (MSE)
If the model is predicting a continuous number (like House Prices), the standard loss function is **MSE**.
$L = rac{1}{n} sum (hat{y} - y)^2$
By squaring the error, MSE mathematically creates a smooth U-shaped curve, ensuring that there is a perfect, calculable derivative pointing exactly to the lowest error. It also heavily punishes massive outliers.

## 2. Binary Classification: Binary Cross-Entropy (BCE)
If the model is predicting a 1 or 0 (like Spam or Not Spam), it outputs a probability (e.g., $0.9$). You cannot use MSE for probabilities because the resulting loss landscape becomes mathematically bumpy (non-convex). 
**BCE** uses logarithms to calculate the error:
$L = - [y log(hat{y}) + (1 - y) log(1 - hat{y})]$
If the true answer is $1$, and the model predicts $0.001$, the logarithm mathematically explodes toward infinity, instantly generating a massive error signal that forces the model to correct itself.

## 3. Multi-Class: Categorical Cross-Entropy
When predicting between 10 different categories (like identifying digits 0-9), the model outputs 10 probabilities that must sum to 1.0 (via Softmax). **Categorical Cross-Entropy** mathematically compares this predicted probability distribution against the true distribution (a one-hot encoded vector), heavily punishing the network if it assigned a low probability to the correct class.
