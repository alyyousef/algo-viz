A **Multi-Layer Perceptron (MLP)** is the most basic, foundational architecture of a deep artificial neural network. When someone uses the generic term "Feed-Forward Neural Network" or "Dense Network," they are almost always referring to an MLP.

## The Architecture

An MLP consists of at least three layers of nodes (neurons):

1.  **Input Layer:** The raw data (e.g., the pixels of an image flattened into a single list, or the numerical features of a dataset).
2.  **Hidden Layer(s):** The core of the network. An MLP can have one hidden layer or hundreds. 
3.  **Output Layer:** The final prediction (e.g., a single number for regression, or a set of probabilities for classification).

### Fully Connected (Dense)
The defining characteristic of an MLP is that it is **fully connected**. 
Every single neuron in Layer 1 is mathematically connected to every single neuron in Layer 2. If Layer 1 has 100 neurons and Layer 2 has 100 neurons, there are exactly $10,000$ weights (connections) between them.

### The Math (Feed-Forward)
Data only flows in one direction (forward). For a single neuron, the math is incredibly simple:
1.  Multiply all incoming inputs by their respective **Weights**.
2.  Add them all together.
3.  Add a **Bias**.
4.  Pass the final number through a non-linear **Activation Function** (like ReLU or Sigmoid).
5.  Send the output to the next layer.

## The Importance of Non-Linearity

A single Perceptron (a network with zero hidden layers) can only draw a straight line. It can only solve linear problems. It famously fails at solving the XOR logic gate problem.

By adding hidden layers and non-linear activation functions, an MLP gains the ability to twist and bend its decision boundaries. According to the **Universal Approximation Theorem**, an MLP with just a single hidden layer (containing enough neurons) can theoretically approximate any continuous mathematical function in the universe.

## Where MLPs Fail

While MLPs are incredibly powerful for structured, tabular data (like predicting housing prices from a CSV file), they fail spectacularly at complex data like images or audio.

1.  **Lack of Spatial Awareness:** To feed an image into an MLP, you must flatten the 2D grid into a 1D list of pixels. The network loses all understanding of shape, geometry, and adjacent pixels.
2.  **Parameter Explosion:** If you feed a $1000 \times 1000$ image into an MLP with just $1000$ hidden neurons, that single layer requires **1 billion weights**. It will instantly run out of memory and massively overfit the training data.

<Callout icon="arrow-right" title="Modern Deep Learning">
Because of these limitations, pure MLPs are rarely used for images or text today. They were entirely superseded by **Convolutional Neural Networks (CNNs)** for images and **Transformers** for text. However, almost every modern network (including CNNs and Transformers) still uses small MLPs at the very end of their architecture to make the final classification prediction.
</Callout>
