An **Activation Function** is a mathematical equation attached to each neuron in a neural network. It decides whether that neuron should be "activated" (fired) or ignored, based on whether the neuron's input is relevant for the model's prediction.

Most importantly, activation functions introduce **non-linearity** into the network.

## Why do we need Non-Linearity?

Without activation functions, a neural network is just a giant series of linear equations (multiplying weights and adding biases). 

Mathematically, if you stack 100 linear layers on top of each other without activation functions, the entire network collapses down into a single linear equation. It would only ever be able to draw straight lines, making it impossible to solve complex, real-world problems (like recognizing a face or translating languages).

By adding a non-linear activation function after every layer, the network gains the ability to twist and bend its decision boundaries, allowing it to approximate almost any function in the universe (The Universal Approximation Theorem).

## Common Activation Functions

### 1. ReLU (Rectified Linear Unit)
**Formula:** $f(x) = \max(0, x)$

ReLU is the undisputed default activation function for hidden layers in modern deep learning.
*   If the input is positive, it returns the input exactly as is.
*   If the input is negative, it returns exactly 0.

**Why it's great:** It is incredibly computationally cheap (just checking if a number is > 0). More importantly, it solves the **Vanishing Gradient Problem**. Because its derivative is a constant $1$ for all positive numbers, gradients can flow backward through a 100-layer deep network without shrinking away to zero, allowing very deep networks to train successfully.
**The "Dying ReLU" Problem:** If a large negative bias is applied, a neuron might always output 0. Once a ReLU neuron always outputs 0, its gradient becomes 0, and it stops learning forever (it "dies"). Variants like **Leaky ReLU** fix this by allowing a tiny negative slope (e.g., $0.01x$) instead of a flat 0.

### 2. Sigmoid
**Formula:** $f(x) = \frac{1}{1 + e^{-x}}$

Sigmoid takes any input (from negative infinity to positive infinity) and squashes it into an S-shaped curve between **0.0 and 1.0**.

**Where it's used:** It is almost exclusively used in the very final output layer of a **Binary Classification** model (e.g., predicting "Cat" vs "Dog"). Because it outputs a value between 0 and 1, it naturally represents a probability (e.g., 85% sure it's a dog).
**Why it's bad for hidden layers:** It severely suffers from the Vanishing Gradient Problem. If the input is a large positive or large negative number, the curve becomes perfectly flat. The derivative (gradient) of a flat line is near zero, meaning learning completely stalls.

### 3. Tanh (Hyperbolic Tangent)
**Formula:** $f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$

Tanh is mathematically similar to Sigmoid, but it squashes values into a range between **-1.0 and 1.0**.

**Where it's used:** It is often used in Recurrent Neural Networks (RNNs) and LSTMs.
**Advantage over Sigmoid:** Because it is zero-centered (the average output is closer to 0), it generally makes the math in the next layer easier, leading to slightly faster convergence than Sigmoid. However, it still suffers heavily from the Vanishing Gradient problem for large inputs.

### 4. Softmax
Softmax is a special activation function used exclusively in the output layer for **Multiclass Classification** (e.g., predicting if an image is a Cat, Dog, or Bird). 

It takes a list of raw scores (logits) from the final layer and converts them into a probability distribution. The outputs will always be between 0 and 1, and crucially, **all the outputs will sum perfectly to 1.0**.

<Callout icon="lightbulb" title="Summary Rule of Thumb">
*   **Hidden Layers:** Use **ReLU** (or a variant like GELU/Swish for modern transformers).
*   **Output Layer (Binary):** Use **Sigmoid**.
*   **Output Layer (Multiclass):** Use **Softmax**.
*   **Output Layer (Regression):** Use **Linear** (no activation function).
</Callout>
