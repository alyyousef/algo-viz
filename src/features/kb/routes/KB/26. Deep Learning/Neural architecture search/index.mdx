**Neural Architecture Search (NAS)** is a subfield of AutoML (Automated Machine Learning). 

For years, designing a state-of-the-art neural network was a manual, painstaking process. Human experts (like the creators of ResNet or the Transformer) would spend months guessing and checking different combinations of layers, filter sizes, and activation functions.

NAS automates this process. Instead of a human designing the network, **we use an AI to design the AI.**

## How NAS Works

A NAS system typically consists of three main components:

### 1. The Search Space
This is the sandbox of rules the AI is allowed to play with. You might tell the NAS system: "You can build a network up to 50 layers deep. You can use Convolutions (size 3x3 or 5x5), Max Pooling, or Dense layers. You can use ReLU or Swish."

### 2. The Search Strategy
This is the algorithm the AI uses to explore the sandbox. 
*   **Reinforcement Learning:** (Used by Google to discover NASNet). An "Agent" network is rewarded if the "Child" network it designs achieves high accuracy.
*   **Evolutionary Algorithms:** It generates a population of random networks. It tests them all, "kills" the worst performers, and "mutates" the best performers to create the next generation of architectures.
*   **Gradient-Based (Differentiable) Search:** The most modern and efficient approach. Instead of training thousands of discrete networks, it creates one massive "Supernet" containing all possible paths and uses standard Gradient Descent to mathematically turn off the bad paths.

### 3. The Performance Estimation Strategy
To know if an architecture is good, you have to test it. Historically, you had to train every single child architecture from scratch to 100 epochs, which took thousands of GPU hours. Modern NAS uses proxies (like training for only 5 epochs, or inheriting weights from a Supernet) to guess how good the network *would* be if fully trained.

## Famous Successes

NAS has produced several state-of-the-art architectures that humans likely never would have designed manually:

*   **NASNet:** Found by Google using Reinforcement Learning. It achieved state-of-the-art accuracy on ImageNet while being significantly smaller than human-designed networks.
*   **EfficientNet:** Designed by scaling up a small baseline network found via NAS. It achieved vastly better accuracy than ResNet while being 8x smaller and 6x faster.

<Callout icon="microchip" title="Hardware-Aware NAS">
One of the most powerful uses of NAS is designing models for specific microchips. You can add a penalty to the AI's reward function based on how much battery power the network uses on an iPhone. The NAS algorithm will automatically discover weird, highly customized architectures that run blazingly fast on iOS, but would run terribly on Android or a desktop GPU.
</Callout>
