**Keras** is a high-level, deep learning API written in Python. Created by François Chollet, it was designed with a single, driving philosophy: **being as user-friendly and intuitive as possible.**

Keras allows data scientists to build, train, and deploy complex neural networks with just a few lines of highly readable code, hiding the intimidating mathematical boilerplate required by lower-level frameworks.

## The Evolution of Keras

Understanding Keras requires understanding its history:

1.  **The Backend Era (2015):** Originally, Keras was purely a frontend interface. It didn't do any math itself. You could configure it to use different "backends" (like TensorFlow, Theano, or CNTK) to do the actual heavy lifting.
2.  **The TensorFlow Merger (2019):** Because it was so incredibly popular, Google officially adopted Keras and merged it directly into TensorFlow 2.0. Keras became `tf.keras`, the default and primary way to interact with TensorFlow.
3.  **Keras 3.0 / Keras Core (2023):** Keras returned to its roots as a multi-backend framework. You can now write Keras code once, and flawlessly run it on top of **TensorFlow, PyTorch, or JAX**, instantly switching backends by changing a single configuration line.

## Core Features

Keras is famous for its simple, composable building blocks. 

### 1. The Sequential API
If your neural network is a simple, straight line of layers (Layer 1 feeds into Layer 2, which feeds into Layer 3), you can build it in seconds using the Sequential API:

```python
import keras
from keras import layers

model = keras.Sequential([
    layers.Dense(64, activation="relu"),
    layers.Dense(64, activation="relu"),
    layers.Dense(10, activation="softmax")
])
```

### 2. The Functional API
If your network requires a more complex topology (e.g., layers that skip over other layers, like in a ResNet, or models with multiple different inputs/outputs), Keras provides the Functional API. It treats layers like functions that take tensors as inputs and return tensors as outputs.

### 3. `compile` and `fit`
Keras revolutionized the training loop. Instead of writing custom gradients and optimization loops by hand, Keras reduces training a model to two lines of code:

```python
# Tell the model how to measure its mistakes and how to fix them
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])

# Train the model on the data
model.fit(x_train, y_train, epochs=10, batch_size=32)
```
