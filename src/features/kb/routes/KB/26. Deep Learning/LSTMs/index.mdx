**Long Short-Term Memory (LSTM)** networks are a highly specialized type of Recurrent Neural Network (RNN) introduced by Sepp Hochreiter and Jürgen Schmidhuber in 1997. 

For nearly 20 years, LSTMs were the undisputed kings of sequential data. If you were doing Speech Recognition (Siri/Alexa), Machine Translation (Google Translate), or Time Series forecasting, you were using an LSTM.

## The Problem with Standard RNNs

Standard RNNs have a "short-term memory." As they process a sentence word by word, they constantly overwrite their hidden state. If an RNN reads a 50-word sentence, by the time it reaches word 50, the math representing word 1 has been multiplied by weights 50 times. 

Because of the **Vanishing Gradient Problem**, those weights shrink to zero during backpropagation, causing the network to completely "forget" the beginning of the sequence.

## How LSTMs Fix It: The Cell State

LSTMs solve this by introducing a second, parallel memory track called the **Cell State** (often referred to as the conveyor belt). 

While the standard Hidden State still gets constantly manipulated and overwritten at every step, the Cell State runs straight down the entire chain with only minor, highly controlled linear interactions. Information can flow down the Cell State completely untouched, allowing gradients to flow backward through 1000-word sequences without vanishing.

## The Three Gates

To control exactly what goes onto (or is removed from) the Cell State conveyor belt, the LSTM uses three mathematical "Gates." Each gate uses a Sigmoid activation function to output a number between 0 (completely block) and 1 (completely let through).

### 1. The Forget Gate
"Should I throw this old memory away?"
It looks at the current word and the previous hidden state. If the network just finished a sentence and saw a period, the Forget gate might output a $0$, completely wiping the old grammar context from the Cell State to prepare for a new sentence.

### 2. The Input Gate
"What new information should I add to the memory?"
It looks at the current word and decides if it contains valuable information. It then creates a candidate vector of new information and uses the Input gate (a percentage) to scale how much of that new information actually gets placed onto the Cell State conveyor belt.

### 3. The Output Gate
"What part of my deep memory should I output right now?"
The Cell State holds a massive amount of long-term context. The Output gate decides which specific pieces of that context are relevant for the *current* word prediction, and outputs only that specific information as the new Hidden State.

<Callout icon="chart-line" title="The Fall of LSTMs">
While LSTMs solved the vanishing gradient problem, they still possess one fatal flaw: **They are inherently sequential.** You cannot process word 50 until you have finished processing word 49. This makes them impossible to train in parallel across modern GPUs. Because of this, LSTMs have been almost entirely replaced by the **Transformer** architecture (which uses Attention to process the entire sequence simultaneously).
</Callout>
