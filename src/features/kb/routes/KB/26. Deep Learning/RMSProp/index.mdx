**RMSProp** (Root Mean Square Propagation) is an advanced optimization algorithm designed to speed up the training of neural networks. 

While rarely used entirely on its own today, RMSProp is incredibly important because it is one of the two core mathematical ingredients that make up the **Adam** optimizer (the most popular optimizer in modern deep learning).

*Fun fact: RMSProp was never actually published in a peer-reviewed academic paper. It was famously introduced by Geoffrey Hinton in Lecture 6e of his 2012 Coursera class, and researchers just started using it because it worked so well.*

## The Problem with Standard Gradient Descent

Standard Stochastic Gradient Descent (SGD) has a major flaw: **It uses the exact same learning rate for every single weight in the entire network.**

Imagine training a network to predict housing prices. 
*   One feature is the "Number of Bedrooms." This feature appears in every single house. Its weight will be updated constantly, thousands of times an epoch.
*   Another feature is "Has a Helipad." This feature is incredibly rare, appearing in maybe 1 out of 100,000 houses. 

If you use a small learning rate, the "Helipad" weight will almost never get updated. If you use a massive learning rate to force the "Helipad" weight to learn quickly, the "Bedrooms" weight will explode and destabilize the network because it's being updated too aggressively.

## How RMSProp Solves It

RMSProp introduces **Adaptive Learning Rates**. It gives *every single weight its own unique, dynamic learning rate.*

It does this by keeping a running average of the *squares* of the gradients for each weight. 

1.  If a weight is being updated constantly with large gradients (like the "Bedrooms" weight), its running average gets very large. RMSProp takes the learning rate and divides it by this large number. This **shrinks** the learning rate for that specific weight, preventing it from exploding.
2.  If a weight is rarely updated (like the "Helipad" weight), its running average stays very close to zero. RMSProp divides the learning rate by this tiny number. This **boosts** the learning rate for that specific weight, allowing it to take a massive step when it finally sees data.

## The Math (Simplified)

For every weight $w$:
1.  Calculate the gradient ($g$).
2.  Update the moving average of the squared gradient: $E[g^2] = 0.9 \times E[g^2] + 0.1 \times g^2$
3.  Update the weight: $w = w - \frac{\alpha}{\sqrt{E[g^2]} + \epsilon} \times g$

*(Where $\alpha$ is the base learning rate, and $\epsilon$ is a tiny number like $10^{-8}$ to prevent dividing by zero).*

<Callout icon="chart-line" title="RMSProp vs AdaGrad">
RMSProp is actually a direct fix for an older optimizer called **AdaGrad**. AdaGrad also adapted learning rates, but it simply summed up all the squared gradients from the beginning of time. Because the sum always grew larger, AdaGrad's learning rates would eventually shrink to exactly zero, freezing the network completely before training finished. RMSProp fixed this by using an *exponential moving average* (it slowly forgets the past), ensuring the learning rate never dies completely.
</Callout>
