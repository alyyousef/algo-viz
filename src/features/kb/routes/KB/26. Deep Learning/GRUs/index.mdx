A **Gated Recurrent Unit (GRU)** is a type of Recurrent Neural Network (RNN) architecture introduced in 2014 by Kyunghyun Cho. 

Like LSTMs (Long Short-Term Memory networks), GRUs were designed to solve the **Vanishing Gradient Problem** that plagues standard RNNs, allowing them to effectively "remember" information over long sequences of data (like long sentences or audio clips). 

## GRU vs LSTM

GRUs and LSTMs accomplish the exact same goal, but GRUs do it with a simpler, more computationally efficient architecture.

An LSTM uses **three** gates (Input, Output, and Forget gates) and maintains **two** separate states (the Hidden State and the Cell State).

A GRU simplifies this by using only **two** gates (Update and Reset gates) and maintaining only **one** state (the Hidden State). Because it has fewer tensor operations and fewer weights to train, a GRU is significantly faster to train and requires less memory than an LSTM, often while achieving identical performance.

## The Architecture of a GRU

The magic of a GRU lies in its two gates, which act as smart filters that decide exactly what information the network should keep and what it should throw away at each step in the sequence.

### 1. The Update Gate
The Update Gate acts like a combination of the LSTM's Forget and Input gates. 
It looks at the current input (e.g., the current word) and the previous hidden state (the context of the sentence so far). It then outputs a value between 0 and 1.
*   **A value close to 1** means: "This new information is incredibly important. Forget what we knew before and update our memory with this."
*   **A value close to 0** means: "This new word is filler (like 'um' or 'the'). Ignore it and keep our old memory exactly as it is."

This ability to effectively bypass the neural network math and just pass the old memory forward perfectly intact is what solves the vanishing gradient problem.

### 2. The Reset Gate
The Reset Gate decides how much of the *past* information should be actively ignored when calculating the *new* candidate memory.
For example, if the network reaches the end of a sentence and sees a period, the Reset Gate might trigger heavily, telling the network to clear out its short-term grammar context because a brand new sentence is about to begin.

<Callout icon="scale-balanced" title="When to use GRU vs LSTM">
Historically, if you had a massive dataset and plenty of compute power, you used an LSTM, as its extra parameters gave it slightly more expressive power. If you had limited compute or a smaller dataset (where an LSTM might overfit), you used a GRU. Today, however, for almost all serious sequence tasks, both GRUs and LSTMs have been heavily superseded by **Transformers**.
</Callout>
