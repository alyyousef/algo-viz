While Ubuntu uses `apt` and Red Hat uses `dnf`, the massive German enterprise Linux vendor SUSE (and its community variant openSUSE) relies entirely on **zypper**.

`zypper` is widely considered one of the most powerful and fastest package managers in the Linux world. It uses the exact same `.rpm` package format as Red Hat, but utilizes a radically different dependency solver called `libzypp`.

## Syntax

`zypper` commands are very straightforward, and it supports ultra-short abbreviations:
- **`sudo zypper refresh` (or `zypper ref`)**: Updates the local cache database.
- **`sudo zypper update` (or `zypper up`)**: Updates all installed software.
- **`sudo zypper install nginx` (or `zypper in nginx`)**: Installs Nginx.


<Callout icon="success" title="The Power of Btrfs Snapshots">


  The true magic of `zypper` is not the command itself, but how openSUSE integrates it with the Btrfs filesystem.
  Every single time you run a `zypper install` command, the operating system instantly takes a freeze-frame snapshot of the entire hard drive. If the software update completely destroys the server and causes a Kernel Panic, you simply reboot, select the previous snapshot in the GRUB boot menu, and the server instantly reverts to exactly how it was 30 seconds ago.


</Callout>
