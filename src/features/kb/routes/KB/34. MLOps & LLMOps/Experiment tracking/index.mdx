Training a Neural Network is not writing code; it is conducting a massive mathematical experiment. If you train 50 models, and Model #42 was the best, but you forgot what Learning Rate you used for Model #42, the experiment is a total failure.

## 1. The Metric Logs
Experiment Tracking tools (like MLflow or Weights & Biases) run as background daemons during training.
Every time the Neural Network completes an Epoch, the script mathematically pushes the exact Training Loss, Validation Loss, and Accuracy to the tracker. The tracker automatically plots these mathematical trajectories on a dashboard. You can instantly see if a model is mathematically diverging (Loss exploding to infinity) and kill the GPU instance to save money.

## 2. The Artifact Bindings
A logged metric is useless without context.
When an experiment finishes, the tracking tool mathematically binds exactly three things together in a single immutable record:
1. The **Hyperparameters** (e.g., Learning Rate = 0.001, Batch Size = 32).
2. The **Dataset Hash** (the exact DVC pointer to the data used).
3. The **Artifacts** (the raw `.pt` model weights generated by the run).
This guarantees absolute scientific reproducibility. Years later, an engineer can look at Run #42 and mathematically recreate it byte-for-byte.
