**Data drift** (covariate shift) is P_serve(x) ≠ P_train(x). A new country, a holiday, a broken tracker that sends zeros, a client that upgraded the camera. The model still emits numbers; they just stopped meaning what they meant in the notebook.

## 1. Deep Dive and Mechanics

**Where to measure.** Raw logs, post-transform features (what the model actually saw), and model scores. Score shift is a cheap catch-all; feature PSI tells you which column moved.

**Univariate vs joint.** PSI per column misses a rotation in a 2-D subspace. For embeddings, use a reference nearest-neighbour distance or a classifier that tries to tell train vs serve.

**Pipeline bugs look like drift.** A unit change (cents vs dollars) is not “the world changed.” Diff schemas and hashes first.

**Action.** Page on sudden PSI; ticket on slow seasonal drift. Retrain only if the new mass is *real* and labelled.

<Callout icon="warning" title="Monitor the served vector">
Training-time pandas and serve-time Flink will diverge. Hash the feature names and dtypes in the model package and reject mismatches.
</Callout>

## 2. Mathematical / Theoretical Foundation

Population Stability Index between expected e_i and actual a_i bins: PSI = sum (a_i - e_i) ln(a_i / e_i). Rules of thumb (0.1 / 0.25) are not laws. JS divergence and KS tests are alternatives. Importance weighting w(x) = P_serve(x)/P_train(x) can correct some estimators if you can model the density ratio.

## 3. Real-World Implementation

```python
import numpy as np

def psi(expected: np.ndarray, actual: np.ndarray, eps=1e-6) -> float:
    e = expected / expected.sum()
    a = actual / actual.sum()
    return float(np.sum((a - e) * np.log((a + eps) / (e + eps))))
```

Fit bins on the training window and freeze them. Re-binning on serve data hides the drift.

## 5. Interview Prep

**Q: Data drift vs concept drift?**
**A:** Data: who arrives. Concept: what y means given x. Both can fire at once.

**Q: Why freeze bins?**
**A:** Adaptive bins on the live window make PSI compare two moving targets. You want “distance from the training snapshot.”

**Q: Is drift always a retrain?**
**A:** No. A tracker outage is a fix, not a new model. Confirm with engineering before you spend a GPU week.

## 6. Production Use Cases

- Credit and insurance models (regulators ask for PSI).
- Recsys after a catalog or app rewrite.
- Vision models after a camera firmware change.

<Callout icon="tip" title="Pair PSI with volume">
A PSI spike on 200 rows is noise. Require a minimum N in the window.
</Callout>
