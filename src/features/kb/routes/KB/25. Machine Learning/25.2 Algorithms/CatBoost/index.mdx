**CatBoost** (Categorical Boosting) is a high-performance open-source gradient boosting on decision trees library developed by Yandex. It is particularly renowned for its exceptional handling of categorical features and its robust performance right out of the box with default hyperparameters.

## Key Features & Advantages

### 1. Native Categorical Feature Handling
The most significant advantage of CatBoost is its ability to process categorical variables directly without requiring manual preprocessing like one-hot encoding or label encoding.

Instead of standard target encoding, CatBoost uses a technique called **Ordered Target Statistics (Ordered TS)**. It calculates the target statistic for a specific row using only the rows that appeared *before* it in a random permutation of the dataset. This prevents **target leakage** (using the target value of a row to encode its own categorical feature) and significantly reduces overfitting.

### 2. Oblivious Trees (Symmetric Trees)
CatBoost uses oblivious decision trees as base predictors. In an oblivious tree, the same splitting criterion is applied across the entire level of the tree.
*   **Faster Execution:** Because the splits are uniform, the tree structure can be evaluated extremely quickly using bitwise operations.
*   **Reduced Overfitting:** The enforced symmetry acts as a natural regularization mechanism, resulting in trees that generalize better.

### 3. Ordered Boosting
Traditional gradient boosting algorithms calculate gradients and build trees using the same dataset, which can lead to prediction shift. CatBoost introduces **Ordered Boosting**, a modification to the standard gradient boosting algorithm that calculates gradients using a separate, independent subset of data for each step, effectively overcoming the prediction shift problem.

<Callout icon="zap" title="Performance">
CatBoost is highly optimized for performance, offering fast training on both CPUs and GPUs. It is often faster to train than XGBoost and competitive with LightGBM, especially when datasets contain many categorical features.
</Callout>
