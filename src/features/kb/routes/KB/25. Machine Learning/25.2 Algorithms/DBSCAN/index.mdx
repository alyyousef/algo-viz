**DBSCAN** (Density-Based Spatial Clustering of Applications with Noise) is a highly popular unsupervised clustering algorithm. Unlike K-Means, which assumes clusters are spherical and requires you to specify the number of clusters in advance, DBSCAN groups points that are closely packed together (high density) and marks points that lie alone in low-density regions as outliers or noise.

## Core Concepts

DBSCAN relies on two crucial hyperparameters to define "density":

1.  **Epsilon (ε):** The maximum distance (radius) around a data point to consider it as part of a neighborhood.
2.  **MinPts:** The minimum number of points required within the Epsilon radius to form a dense region (a cluster).

Based on these parameters, DBSCAN categorizes every data point into one of three types:

*   **Core Point:** A point that has at least *MinPts* points (including itself) within its *Epsilon* neighborhood. These points form the interior of a cluster.
*   **Border Point:** A point that has fewer than *MinPts* within its neighborhood, but is located within the neighborhood of a Core Point. These points form the edges of a cluster.
*   **Noise Point (Outlier):** A point that is neither a Core Point nor a Border Point. It is not part of any cluster.

## How the Algorithm Works

1.  **Initialization:** The algorithm starts with an arbitrary point that has not been visited.
2.  **Neighborhood Check:** It extracts the pointTICK1s Epsilon neighborhood.
3.  **Cluster Formation:**
    *   If the neighborhood contains fewer than *MinPts*, the point is marked as noise (though this may be updated later if it is found within the neighborhood of a different core point).
    *   If the neighborhood contains at least *MinPts*, a cluster is started. The starting point and its neighbors are added to the cluster.
4.  **Expansion:** The algorithm then repeats this process for all points within the newly formed cluster, recursively expanding the cluster until no more points can be added.
5.  **Iteration:** It proceeds to the next unvisited point in the dataset, repeating the process until all points have been visited.

<Callout icon="chart-line" title="Handling Noise">
DBSCAN is uniquely powerful because it explicitly identifies noise. Algorithms like K-Means force every point into a cluster, even extreme outliers, which can severely distort the cluster boundaries.
</Callout>

## Advantages and Disadvantages

### Advantages
*   Does not require specifying the number of clusters ($k$) beforehand.
*   Can discover clusters of arbitrary shapes (e.g., a cluster surrounding another cluster), whereas K-Means struggles with anything non-spherical.
*   Robust to outliers; it isolates them as noise.

### Disadvantages
*   Struggles with datasets where clusters have significantly different densities, because a single Epsilon and MinPts value cannot capture varying densities well. (An extension called **OPTICS** addresses this).
*   Can be sensitive to the choice of the distance metric (often Euclidean), especially in high-dimensional spaces (the "Curse of Dimensionality").
*   Choosing the optimal Epsilon and MinPts requires domain knowledge or careful tuning (e.g., using a k-distance graph).
