**Lasso Regression** (Least Absolute Shrinkage and Selection Operator) is a type of linear regression that uses shrinkage. Shrinkage is where data values are shrunk towards a central point, like the mean. Lasso is highly favored because it performs both regularization and automated feature selection.

## The Objective Function

In standard Linear Regression (Ordinary Least Squares), the goal is to find the weights ($w$) that minimize the Residual Sum of Squares (RSS).

Lasso modifies this by adding a penalty term equivalent to the **absolute value of the magnitude of the coefficients** (this is known as the **L1 penalty**).

$$L = \text{RSS} + \lambda \sum_{j=1}^{p} |w_j|$$

Where:
*   $w_j$ are the feature weights.
*   $\lambda$ (lambda) is the tuning parameter (hyperparameter) that controls the strength of the penalty. 
    *   If $\lambda = 0$, you get standard Linear Regression.
    *   As $\lambda \to \infty$, the penalty dominates, and all coefficients are forced to zero.

## Feature Selection (Sparsity)

The defining characteristic of Lasso, and the reason it is so widely used, is that it forces the coefficients of less important features to become **exactly zero**. 

This happens because the L1 penalty creates a diamond-shaped constraint region in the parameter space. The objective function (the RSS contours) is highly likely to intersect this diamond at its sharp corners (where one or more coefficients are zero).

<Callout icon="lightbulb" title="Why is this useful?">
By driving coefficients to zero, Lasso performs **automatic feature selection**. If you start with 1,000 features, a well-tuned Lasso model might end up using only 20 of them, ignoring the rest. This creates a "sparse" model that is much easier to interpret, requires less memory, and is significantly less prone to overfitting than a standard linear model.
</Callout>

## Limitations of Lasso

While powerful, Lasso has specific weaknesses where Ridge Regression or Elastic Net might perform better:

1.  **Correlated Features:** If two or more features are highly correlated with each other, Lasso will essentially pick one at random, keep its coefficient, and drive the others to zero. It doesn't care which one it keeps.
2.  **High Dimensionality ($p > n$):** If the number of features ($p$) is strictly greater than the number of observations ($n$), Lasso can only select a maximum of $n$ features before the model saturates.

## Summary

Lasso Regression is a powerful tool in a data scientist's arsenal when dealing with high-dimensional datasets where feature selection is required. It simultaneously prevents overfitting (via regularization) and produces a simpler, more interpretable model by eliminating useless predictors.
