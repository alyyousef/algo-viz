Despite having "regression" in its name, **Logistic Regression** is a fundamental supervised machine learning algorithm used primarily for **classification**, not regression. It is the go-to algorithm for predicting categorical outcomes, most commonly binary outcomes (e.g., Yes/No, Spam/Not Spam, Malignant/Benign).

## The Core Concept: From Linear to Logistic

If you try to use Linear Regression ($y = w_0 + w_1x_1 + ...$) for a binary classification problem (where $y$ is 0 or 1), the model will output values less than 0 or greater than 1, which doesn't make sense as a probability.

Logistic Regression solves this by taking the output of a linear equation and passing it through a mathematical function called the **Sigmoid function** (or Logistic function).

### The Sigmoid Function

The Sigmoid function squashes any real-valued number into a range exactly between 0 and 1. 

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Where $z$ is the linear combination of inputs: $z = w_0 + w_1x_1 + w_2x_2 + ...$

By passing the linear equation through the Sigmoid function, Logistic Regression outputs a value between 0 and 1, which can be interpreted as the **probability** that the given data point belongs to the positive class (class 1).

## Making a Classification Decision

To turn the probability output into a concrete classification, a **decision threshold** is applied. 
*   If the predicted probability $\ge 0.5$, classify as Class 1.
*   If the predicted probability $< 0.5$, classify as Class 0.

<Callout icon="lightbulb" title="Adjusting the Threshold">
The threshold does not have to be 0.5. In medical diagnosis, you might want to avoid False Negatives (missing a disease). You could lower the threshold to 0.2, meaning the model only needs to be 20% confident to flag a patient for further screening, thereby increasing Recall at the expense of Precision.
</Callout>

## How the Model Learns (Log Loss)

Linear Regression uses Mean Squared Error (MSE) as its cost function. If you use MSE with the Sigmoid function, the resulting cost function becomes non-convex (it has many local valleys), making Gradient Descent ineffective.

Instead, Logistic Regression uses **Log Loss** (also known as Binary Cross-Entropy). 
Log Loss heavily penalizes the model when it is highly confident but wrong. 
*   If the true class is 1 and the model predicts 0.99, the penalty is tiny.
*   If the true class is 1 and the model predicts 0.01, the penalty is massive.

The algorithm uses optimization techniques like Gradient Descent to find the weights that minimize the overall Log Loss across the training data.

## Advantages and Limitations

### Advantages
*   **Interpretability:** Like Linear Regression, the weights assigned to features are highly interpretable. A positive weight means the feature increases the probability of class 1; a negative weight decreases it.
*   **Outputs Probabilities:** It doesn't just give a hard "yes/no" answer; it tells you *how confident* it is.
*   **Fast and Efficient:** It is computationally cheap to train and extremely fast at inference time.

### Limitations
*   **Linear Decision Boundary:** It assumes the classes can be separated by a single straight line (or flat hyperplane in higher dimensions). It cannot solve non-linear problems (like the XOR problem) without complex feature engineering.
*   **Multiclass Classification:** While natively binary, it can be extended to multiclass problems using techniques like One-vs-Rest (OvR) or Multinomial Logistic Regression (Softmax), but algorithms like Random Forests are often preferred for complex multiclass tasks.
