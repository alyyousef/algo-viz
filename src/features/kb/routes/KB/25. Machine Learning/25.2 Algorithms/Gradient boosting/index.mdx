**Gradient Boosting** is one of the most powerful and widely used machine learning algorithms for tabular data. It is an ensemble technique—specifically a **boosting** technique—that builds a strong predictive model by combining the predictions of multiple weak models (typically shallow Decision Trees).

## The Core Idea of Boosting

Unlike **Bagging** (e.g., Random Forests), where models are built independently in parallel and their predictions are averaged, **Boosting** builds models sequentially. Each new model is specifically trained to correct the errors made by the combination of all previous models.

## How Gradient Boosting Works

1.  **Initial Prediction:** The algorithm starts with a very simple, naive prediction for all observations (usually the mean of the target variable for regression tasks).
2.  **Calculate Pseudo-Residuals:** For each data point, it calculates the "residual"—the difference between the actual target value and the current prediction. In gradient boosting, these are treated as the negative gradient of the loss function, indicating the direction we need to move to improve our predictions.
3.  **Build a Weak Learner:** A new, shallow Decision Tree is trained to predict these residuals, *not* the original target values.
4.  **Update Predictions:** The predictions of this new tree are multiplied by a **learning rate** (to prevent overfitting) and added to the previous predictions.
5.  **Iterate:** Steps 2-4 are repeated for a specified number of iterations (trees), continually chipping away at the remaining errors.

<Callout icon="chart-line" title="The Role of Gradient Descent">
The "Gradient" in Gradient Boosting comes from the fact that the algorithm uses gradient descent in function space to minimize an arbitrary differentiable loss function. Fitting a tree to the residuals is mathematically equivalent to taking a step in the direction that most steeply reduces the loss.
</Callout>

## Key Hyperparameters

Gradient boosting is highly sensitive to hyperparameters and requires careful tuning:
*   **Number of Trees (`n_estimators`):** Adding too many trees can lead to overfitting.
*   **Learning Rate (`eta`):** Scales the contribution of each tree. A lower learning rate requires more trees but usually results in a better generalizing model.
*   **Tree Depth (`max_depth`):** Usually kept small (e.g., 3-7). We want *weak* learners.

## Modern Implementations

While standard Gradient Boosting is effective, it can be slow to train. Modern libraries have heavily optimized the algorithm:
*   **XGBoost (Extreme Gradient Boosting):** Popularized the algorithm with hardware optimization, regularization, and handling of missing values.
*   **LightGBM:** Developed by Microsoft, it uses a histogram-based approach for faster training and lower memory usage, growing trees leaf-wise rather than depth-wise.
*   **CatBoost:** Developed by Yandex, specialized in handling categorical features natively without extensive preprocessing.
