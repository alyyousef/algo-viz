**Linear Regression** is one of the most fundamental and widely used algorithms in statistics and machine learning. It is a supervised learning algorithm used for predicting a **continuous** target variable based on one or more predictor variables (features).

The core idea is to find a linear relationship (a straight line, or a hyperplane in higher dimensions) that best fits the data points.

## The Mathematical Model

The model assumes that the target variable ($y$) is a linear combination of the input features ($x_1, x_2, ..., x_n$):

$$y = w_0 + w_1x_1 + w_2x_2 + ... + w_nx_n$$

*   $y$: The predicted value (target).
*   $x_i$: The input features.
*   $w_i$: The weights (coefficients) that the model learns. 
*   $w_0$: The bias term (y-intercept).

If there is only one input feature, it is called **Simple Linear Regression** ($y = mx + b$). If there are multiple features, it is called **Multiple Linear Regression**.

## How the Model Learns (Cost Function)

To find the "best fit" line, the algorithm must define what "best" means. It does this using a cost function, typically the **Mean Squared Error (MSE)** or the **Residual Sum of Squares (RSS)**.

The algorithm calculates the difference between the actual value and the predicted value (the residual or error), squares it, and sums it across all data points. The goal of the algorithm is to find the weights ($w$) that **minimize this cost function**.

<Callout icon="chart-line" title="Optimization Methods">
There are two primary ways to find the weights that minimize the MSE:
1.  **Ordinary Least Squares (OLS) / Normal Equation:** A closed-form mathematical solution that calculates the optimal weights directly using matrix calculus. It is fast for small datasets but computationally expensive for datasets with millions of features.
2.  **Gradient Descent:** An iterative optimization algorithm that gradually tweaks the weights to move down the slope of the cost function until it reaches the minimum. This is highly scalable to massive datasets.
</Callout>

## Assumptions of Linear Regression

For a linear regression model to be reliable and statistically sound, it assumes several things about the data (often remembered by the acronym LINE):

1.  **Linearity:** The relationship between the independent variables and the target variable is linear.
2.  **Independence:** The observations are independent of each other (no autocorrelation, especially important in time series).
3.  **Normality of Errors:** The residuals (errors) are normally distributed.
4.  **Equal Variance (Homoscedasticity):** The variance of the residuals is constant across all levels of the independent variables (the spread of errors shouldn't look like a cone).

## Limitations

*   **Underfitting:** It is a very rigid model. If the true relationship in the data is highly non-linear, a linear regression model will perform poorly (high bias).
*   **Sensitivity to Outliers:** Because it squares the errors (MSE), a single massive outlier can drastically skew the line of best fit.
*   **Multicollinearity:** If the input features are highly correlated with each other, it becomes difficult for the model to determine the individual effect of each feature, leading to unstable weights.
