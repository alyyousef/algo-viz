**Ridge Regression** is a regularization technique used to analyze multiple regression data that suffer from multicollinearity (independent variables are highly correlated). By adding a degree of bias to the regression estimates, Ridge Regression drastically reduces the standard errors and prevents overfitting, resulting in a model that generalizes better to unseen data.

## The Objective Function

Standard Linear Regression (Ordinary Least Squares) tries to minimize the Residual Sum of Squares (RSS). 

Ridge Regression modifies this cost function by adding an **L2 penalty**, which is equivalent to the **square of the magnitude of the coefficients**.

$$L = \text{RSS} + \lambda \sum_{j=1}^{p} w_j^2$$

Where:
*   $w_j$ are the feature weights (coefficients).
*   $\lambda$ (lambda) is the tuning parameter (hyperparameter) that controls the strength of the penalty.
    *   If $\lambda = 0$, the penalty term is zero, and the model is identical to standard Linear Regression.
    *   As $\lambda \to \infty$, the penalty grows, forcing the coefficients to approach zero (but never exactly zero).

## The Effect on Coefficients (Shrinkage)

The primary effect of the L2 penalty is **shrinkage**. It pulls the coefficients of the model closer to zero. 
Why is this helpful?
*   In standard linear regression, if features are correlated, the model might assign massive positive weights to one feature and massive negative weights to another to cancel them out, making the model incredibly unstable.
*   The squared penalty ($\sum w_j^2$) heavily punishes exceptionally large coefficients. To minimize the cost function, the model is forced to distribute the weights more evenly across all correlated features, resulting in a much more stable and robust model.

<Callout icon="exclamation-triangle" title="Does not perform feature selection">
Unlike Lasso Regression (L1 regularization), the L2 penalty in Ridge Regression will shrink coefficients *towards* zero, but it will **never force them to be exactly zero**. Therefore, Ridge Regression will always keep all the features in the model. If you need automatic feature selection, use Lasso or Elastic Net instead.
</Callout>

## When to Use Ridge Regression

1.  **Multicollinearity:** When your dataset has features that are highly correlated with each other.
2.  **Preventing Overfitting:** When a standard linear model performs well on the training data but poorly on the test data (high variance).
3.  **Many Features:** When you have a large number of features and you believe that *most* of them contribute at least a little bit to the target variable (meaning you don't want to discard them completely).

## Summary

Ridge Regression is a fundamental and widely used regularization technique. By penalizing the squares of the model coefficients, it trades a small amount of bias for a significant reduction in variance, producing stable, reliable linear models even in the presence of highly correlated data.
