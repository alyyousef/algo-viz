<ConceptTemplate title="Gaussian Mixture Models (GMM)">

K-Means clustering is mathematically rigid. It draws a strict circular boundary and assigns a data point to exactly one cluster (Hard Clustering). 

**Gaussian Mixture Models (GMM)** use probability calculus to perform **Soft Clustering**. It mathematically assumes that the dataset is generated by a mixture of multiple Gaussian (Normal) distributions, and calculates the exact *probability* that a data point belongs to a specific cluster.

## 1. The Mathematical Assumption
If you have a dataset of human heights, you might mathematically assume it is generated by two overlapping Gaussian distributions: one for Men, one for Women.
A GMM mathematically defines each cluster using three parameters:
- **Mean ($\mu$)**: The center of the bell curve.
- **Covariance ($\Sigma$)**: The mathematical width and shape of the bell curve (allowing the cluster to be an elongated oval, not just a perfect sphere).
- **Mixing Probability ($\pi$)**: The size/weight of the cluster (e.g., 60% of the dataset belongs to Cluster 1).

## 2. Expectation-Maximization (EM) Algorithm
Because the algorithm does not know the Mean, Covariance, or the Labels, it is caught in a mathematical paradox. It solves this using the **Expectation-Maximization (EM)** algorithm.

1. **Initialization**: Randomly guess the Means and Covariances of $K$ Gaussians.
2. **Expectation Step (E-Step)**: Use Bayes' Theorem to mathematically calculate the probability that every single data point belongs to each Gaussian. (e.g., Point A has a 70% chance of being in Cluster 1, and 30% for Cluster 2).
3. **Maximization Step (M-Step)**: Mathematically update the Mean and Covariance of the Gaussians to perfectly fit the probabilistic assignments calculated in the E-Step.
4. **Repeat**: Loop E and M until the Gaussians mathematically stop moving (Convergence).

## 3. Advantages over K-Means
- **Covariance Flexibility**: K-Means mathematically forces clusters to be spherical. GMMs mathematically allow clusters to be long, stretched ellipses, perfectly wrapping around elliptical data.
- **Probabilistic Output**: If a data point is on the border of two clusters, K-Means violently forces it into one. GMM outputs the mathematical nuance: "There is a 51% chance it is Cluster A, and 49% chance it is Cluster B."
