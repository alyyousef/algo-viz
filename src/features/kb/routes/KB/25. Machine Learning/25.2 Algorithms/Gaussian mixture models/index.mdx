A **Gaussian Mixture Model (GMM)** is a probabilistic model that assumes all the data points are generated from a mixture of a finite number of Gaussian (normal) distributions with unknown parameters. 

While algorithms like K-Means perform *hard clustering* (a point belongs entirely to one cluster), GMMs perform **soft clustering**. For any given data point, a GMM outputs the *probability* that the point belongs to each of the clusters.

## The Core Concept

Imagine a dataset of heights. Instead of assuming one normal distribution for everyone, a GMM might assume the data is generated by two overlapping Gaussian distributions: one for men and one for women.

A GMM is parameterized by three things for each of its $k$ Gaussian components:
1.  **Mean ($\mu$):** The center of the Gaussian.
2.  **Covariance ($\Sigma$):** Defines the shape, size, and orientation of the Gaussian. Unlike K-Means, which assumes spherical clusters, the covariance matrix allows GMMs to model elliptical (oval) clusters.
3.  **Mixing Weight ($\pi$):** The probability that a randomly selected data point belongs to this specific Gaussian component (the weights of all components sum to 1).

## Expectation-Maximization (EM) Algorithm

Because we don't know the parameters of the Gaussians or which point belongs to which Gaussian, GMMs are trained using the **Expectation-Maximization (EM)** algorithm, an iterative process:

1.  **Initialization:** Randomly guess the parameters ($\mu$, $\Sigma$, $\pi$) for the $k$ components.
2.  **Expectation (E-step):** Using the current parameters, calculate the probability (responsibility) that each data point was generated by each of the $k$ components.
3.  **Maximization (M-step):** Update the parameters ($\mu$, $\Sigma$, $\pi$) of each component to maximize the likelihood of the data, using the probabilities calculated in the E-step as weights.
4.  **Repeat:** Iterate the E and M steps until the parameters converge (stop changing significantly).

<Callout icon="exclamation-triangle" title="Local Optima">
Like K-Means, the EM algorithm for GMMs is sensitive to initialization and can get stuck in local optima. It is common practice to run the algorithm multiple times with different random initializations and pick the model with the highest likelihood.
</Callout>

## Summary

GMMs are powerful tools for both clustering and density estimation. By providing probabilities of cluster membership and supporting elliptical cluster shapes, they offer a significantly more flexible and nuanced approach to unsupervised learning compared to strict distance-based algorithms like K-Means.
