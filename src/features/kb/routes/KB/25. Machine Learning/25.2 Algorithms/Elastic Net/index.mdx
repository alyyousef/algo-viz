**Elastic Net** is a regularized linear regression model that linearly combines the penalties of both **Lasso (L1)** and **Ridge (L2)** methods. It was designed to overcome some of the limitations of Lasso, particularly when dealing with highly correlated features.

## The Problem with Lasso

Lasso (L1 regularization) is excellent for feature selection because it can shrink the coefficients of less important features exactly to zero. However, it struggles in two main scenarios:
1.  **$p > n$ Case:** If the number of predictors ($p$) is greater than the number of observations ($n$), Lasso can select at most $n$ predictors before it saturates.
2.  **Highly Correlated Features:** If there is a group of highly correlated features, Lasso tends to arbitrarily select only one feature from the group and ignore the others.

## How Elastic Net Works

Elastic Net solves these problems by incorporating both the absolute value penalty (L1) and the squared magnitude penalty (L2) into the loss function.

The objective function to minimize becomes:
$$L = \text{Loss Function} + \lambda_1 \sum |w_i| + \lambda_2 \sum w_i^2$$

Often, the hyperparameters are re-parameterized as:
*   **$\alpha$ (alpha):** The overall strength of the penalty.
*   **$\text{l1\_ratio}$:** The mixing parameter between 0 and 1.
    *   If `l1_ratio = 1`, the penalty is pure Lasso.
    *   If `l1_ratio = 0`, the penalty is pure Ridge.
    *   If $0 < \text{l1\_ratio} < 1$, it is Elastic Net.

## Advantages

*   **Groups Correlated Features:** Unlike Lasso, which arbitrarily picks one correlated feature, Elastic Net encourages a grouping effect, where strongly correlated predictors tend to be selected (or excluded) together.
*   **Handles $p > n$:** The Ridge (L2) component helps it overcome the limitation of Lasso, allowing it to select more than $n$ predictors if necessary.
*   **Best of Both Worlds:** It provides the sparsity of Lasso (feature selection) while maintaining the stability and grouping effect of Ridge regression.

<Callout icon="lightbulb" title="When to use Elastic Net">
Elastic Net is generally the preferred regularized regression method over Lasso or Ridge when you have a dataset with many features that might be correlated with one another, or when you are unsure whether L1 or L2 regularization will perform better.
</Callout>
