**Precision** (also known as Positive Predictive Value) is a metric used to evaluate classification models. It answers a very specific question: 

*"Out of all the instances the model predicted as Positive, how many were actually Positive?"*

In simpler terms, it measures the **quality** or **trustworthiness** of the model's positive alarms. If a high-precision model flags something as positive, you can be highly confident that it is correct.

## The Formula

Precision is calculated using values from the Confusion Matrix:

$$\text{Precision} = \frac{\text{True Positives (TP)}}{\text{True Positives (TP)} + \text{False Positives (FP)}}$$

*   **True Positives:** The model predicted a dog, and it was a dog.
*   **False Positives:** The model predicted a dog, but it was actually a cat (a false alarm).

If the model makes zero False Positives, its precision is a perfect 1.0 (100%).

## When to Optimize for Precision

You should optimize your model for Precision when the **cost of a False Positive is very high**.

<Callout icon="envelope" title="Example: Spam Filters">
Imagine building an email spam filter.
*   A **False Negative** means a spam email gets into your inbox. This is annoying, but harmless.
*   A **False Positive** means a critical email from your boss or a bank statement gets sent to the spam folder, and you never see it. This is disastrous.

Because False Positives are so costly in this scenario, you want a spam filter with incredibly high Precision. You only want it to flag an email as spam if it is 99.9% sure. 
</Callout>

Other examples where Precision is paramount:
*   **YouTube Recommendations:** If YouTube recommends a terrible video (False Positive), you might close the app.
*   **Criminal Justice:** It is generally considered worse to falsely convict an innocent person (False Positive) than to let a guilty person go free (False Negative).

## The Tradeoff with Recall

Precision is only half of the story. It is almost always evaluated in tandem with **Recall** (Sensitivity).

*   **Precision:** Quality of positive predictions. (Minimizes False Positives).
*   **Recall:** Quantity of actual positives found. (Minimizes False Negatives).

You can easily build a model with 100% Precision: just have it predict "Negative" for everything, except for the one single instance it is absolutely, mathematically certain is Positive. It will have 100% Precision, but a Recall near 0% because it missed almost everything.

Because of this tradeoff, we often use the **F1 Score** (the harmonic mean of Precision and Recall) or plot a **Precision-Recall Curve** to evaluate the overall effectiveness of a model on imbalanced datasets.
