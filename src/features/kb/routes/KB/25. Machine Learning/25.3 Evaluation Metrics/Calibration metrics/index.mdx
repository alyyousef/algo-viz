In machine learning, many classification models (like Logistic Regression, Random Forests, or Neural Networks) output a score between 0 and 1, which we often interpret as a **probability**. 

However, just because a model outputs "0.8" doesn't mean it's actually 80% confident. 

**Model Calibration** is the degree to which a model's predicted probabilities align with the true, real-world frequencies of the outcomes. 
*   If a perfectly calibrated model predicts "0.8" for 100 different patients, exactly 80 of those patients should actually have the disease.
*   If only 50 of them have the disease, the model is **overconfident**.
*   If 95 of them have the disease, the model is **underconfident**.

Calibration metrics help us measure and visualize this discrepancy.

## 1. Reliability Diagrams (Calibration Curves)

The most common way to evaluate calibration is visually using a **Reliability Diagram**.

1.  Take all the predictions made by the model and divide them into "bins" (e.g., 10 bins: 0.0-0.1, 0.1-0.2, etc.).
2.  For each bin, calculate the **average predicted probability** (e.g., the average of all predictions falling in the 0.7-0.8 bin might be 0.75).
3.  For each bin, calculate the **true fraction of positives** (e.g., out of all the samples in that bin, what percentage actually belonged to the positive class?).
4.  Plot these two values against each other.

A perfectly calibrated model will follow a straight 45-degree diagonal line ($y = x$). 
*   If the curve dips below the diagonal, the model is overconfident (predicting higher probabilities than reality).
*   If the curve bows above the diagonal, the model is underconfident.

## 2. Brier Score

The Brier Score is the most common quantitative metric for calibration. It is simply the Mean Squared Error (MSE) applied to predicted probabilities.

$$\text{Brier Score} = \frac{1}{N} \sum_{i=1}^{N} (f_i - o_i)^2$$

Where:
*   $f_i$ is the predicted probability.
*   $o_i$ is the actual outcome (1 if it happened, 0 if it didn't).

The Brier Score ranges from 0 to 1. A score of 0 indicates perfect calibration. A lower score is always better.

## 3. Expected Calibration Error (ECE)

Expected Calibration Error takes the bins used in the Reliability Diagram and calculates the weighted average difference between the predicted probabilities and the true fractions of positives.

It directly quantifies the "gap" between the model's calibration curve and the perfect diagonal line. Like the Brier Score, a lower ECE is better.

<Callout icon="exclamation-triangle" title="Deep Learning Models are poorly calibrated">
Modern, highly complex deep neural networks are notoriously poorly calibrated. They tend to be exceptionally overconfident, outputting probabilities like 0.999 even when they are completely wrong. Algorithms like Logistic Regression, on the other hand, tend to be naturally well-calibrated.
</Callout>

## How to fix poor calibration

If your model is poorly calibrated (which is dangerous in fields like medicine or finance where uncertainty must be measured accurately), you can apply **post-training calibration techniques**:
*   **Platt Scaling (Logistic Calibration):** Fitting a logistic regression model on top of your model's outputs to squash the probabilities into a calibrated curve.
*   **Isotonic Regression:** A non-parametric approach that fits a piecewise constant, non-decreasing function to the outputs. It is more powerful than Platt Scaling but requires more data to avoid overfitting.
