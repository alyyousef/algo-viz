**ROUGE** (Recall-Oriented Understudy for Gisting Evaluation) is a set of metrics used in Natural Language Processing (NLP) specifically designed to evaluate automatic summarization (and sometimes machine translation).

While the older metric **BLEU** focuses heavily on *Precision* (did the machine only use correct words?), **ROUGE** focuses heavily on *Recall* (did the machine capture all the important information that was in the human reference?).

## Why Summarization Needs Recall

Imagine a 5-page document about the causes of World War 1. A human summarizes it in 5 sentences.

*   **Machine Summary A:** Outputs exactly one sentence: *"World War 1 happened."*
    *   This is perfectly true. The grammar is flawless. A precision-based metric (like BLEU) might score this highly. But as a summary, it is terrible because it missed 95% of the important details.
*   **Machine Summary B:** Outputs a 5-sentence paragraph covering alliances, the assassination of Archduke Ferdinand, and militarism.
    *   This is a good summary because it *recalled* the most critical information.

## The Different Types of ROUGE

ROUGE is not a single metric, but a family of metrics based on overlapping n-grams, word sequences, and word pairs. The three most common are:

### 1. ROUGE-N (N-gram overlap)
ROUGE-N measures the number of matching n-grams between the model's summary and a human reference summary.
*   **ROUGE-1:** Measures the overlap of unigrams (single words). This checks if the summary captured the key vocabulary.
*   **ROUGE-2:** Measures the overlap of bigrams (two-word phrases). This helps assess fluency and word order.

$$\text{ROUGE-N Recall} = \frac{\text{Number of matching N-grams}}{\text{Total N-grams in Human Reference}}$$

### 2. ROUGE-L (Longest Common Subsequence)
ROUGE-L looks for the Longest Common Subsequence (LCS) between the machine summary and the human summary.
Unlike n-grams, which require words to be strictly consecutive (next to each other), LCS allows for words to be separated by other words, as long as they appear in the same *order*. This makes it much more robust to phrasing differences.

### 3. ROUGE-S (Skip-Bigram Co-occurrence)
ROUGE-S measures skip-bigrams. A skip-bigram is any pair of words in their sentence order, allowing for arbitrary gaps between them.

## F1 Score in ROUGE

While ROUGE was designed to be recall-focused, most modern libraries (like the `rouge-score` package in Python) will calculate **Precision, Recall, and the F1 Score** for every ROUGE metric.

*   **ROUGE Recall:** How much of the human reference did the machine capture?
*   **ROUGE Precision:** How much of the machine's summary was actually relevant? (This penalizes the machine for writing a 50-page summary just to ensure it caught everything).
*   **ROUGE F1:** The harmonic mean of the two, which is usually the final reported number in academic papers.

<Callout icon="triangle-exclamation" title="The Limits of ROUGE">
Like BLEU, standard ROUGE only looks for exact string matches. If the human writes "The economy grew rapidly" and the machine writes "Financial markets expanded quickly," the ROUGE score is 0, even though the semantic meaning is identical. Modern evaluations often supplement ROUGE with neural metrics like BERTScore.
</Callout>
