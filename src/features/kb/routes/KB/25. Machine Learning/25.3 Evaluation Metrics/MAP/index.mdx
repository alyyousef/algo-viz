**MAP (Mean Average Precision)** is a popular evaluation metric used heavily in two distinct areas of machine learning: **Information Retrieval** (like search engines or recommender systems) and **Computer Vision** (specifically Object Detection).

It is designed to evaluate algorithms that return a ranked list of items or multiple overlapping predictions.

## 1. MAP in Information Retrieval

Imagine you search Google for "cute cats". Google returns a list of 100 links. You want the relevant links to be at the very top of page 1, not buried on page 10.

*   **Precision:** What percentage of the returned links are actually about cats?
*   **Precision at K (P@K):** What is the precision if we only look at the top $K$ results? (e.g., P@5 means the precision of just the first 5 links).

**Average Precision (AP)** for a single search query is calculated by finding the Precision at $K$ *only at the ranks where a relevant document is found*, and then averaging those values. It heavily rewards models that put relevant documents at the very top of the list.

**Mean Average Precision (mAP)** is simply the average of the AP scores across *all* the different search queries in your test set.

## 2. MAP in Object Detection

In object detection (like YOLO or Faster R-CNN), the model draws a bounding box around objects (e.g., a car) and gives a confidence score (e.g., 90% sure). Evaluating this is complex because the model might draw 5 overlapping boxes around the same car.

To calculate mAP in computer vision, we follow these steps:

### Step 1: Intersection over Union (IoU)
First, we determine if a predicted bounding box is correct. We calculate the IoU: the area where the predicted box and the true ground-truth box overlap, divided by their total combined area.
If IoU > Threshold (usually 0.5), it is a True Positive. Otherwise, it is a False Positive.

### Step 2: Precision-Recall Curve
For a single class (e.g., "Cars"), we sort all the model's predictions by confidence score (highest to lowest). We then calculate the Precision and Recall as we go down the list. We plot this on a Precision-Recall Curve.

### Step 3: Average Precision (AP)
The **AP** for the "Car" class is the Area Under the Precision-Recall Curve (AUC-PR). It summarizes the model's performance for cars across all confidence thresholds.

### Step 4: Mean Average Precision (mAP)
Finally, we calculate the AP for every single class (Cars, Pedestrians, Bicycles, Traffic Lights) and take the average of all those APs. That final number is the **mAP**.

<Callout icon="chart-simple" title="mAP Notations (COCO Dataset)">
In object detection, mAP is highly dependent on the chosen IoU threshold. 
*   **mAP@0.5:** mAP calculated requiring an IoU of at least 50% to be a True Positive. (Also called AP50).
*   **mAP@[0.5:0.95]:** This is the primary metric for the famous COCO dataset. It calculates the mAP at an IoU of 0.5, then 0.55, then 0.6... all the way to 0.95, and averages all of them together. It rigorously tests both classification accuracy *and* bounding box tightness.
</Callout>
