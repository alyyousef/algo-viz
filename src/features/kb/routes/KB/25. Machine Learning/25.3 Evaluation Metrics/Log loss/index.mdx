**Log Loss** (short for Logarithmic Loss, also heavily known as **Binary Cross-Entropy** in deep learning) is the standard loss function used to evaluate and train classification models that output probabilities (like Logistic Regression and Neural Networks).

While metrics like Accuracy evaluate the final *hard prediction* (e.g., "Is it a cat? Yes."), Log Loss evaluates the *confidence* of the prediction (e.g., "It is a cat with 99% probability").

## The Goal of Log Loss

The objective of a machine learning model is to minimize its loss function. A perfect model would have a Log Loss of exactly $0.0$. 

Log Loss heavily penalizes a model for being **confident and wrong**.
*   If the true label is 1, and the model predicts 0.95, the penalty (loss) is very small.
*   If the true label is 1, and the model predicts 0.50 (unsure), the penalty is moderate.
*   If the true label is 1, and the model predicts 0.01 (confident it's a 0), the penalty is **massive**.

## The Formula

For a single observation in a binary classification problem, the Log Loss is defined as:

$$\text{Log Loss} = -[y \cdot \log(p) + (1 - y) \cdot \log(1 - p)]$$

Where:
*   $y$ is the true label (either $0$ or $1$).
*   $p$ is the predicted probability that the observation belongs to class $1$.
*   $\log$ is the natural logarithm (base $e$).

<Callout icon="calculator" title="Understanding the Math">
Because $y$ can only be 0 or 1, one half of the equation always disappears:
*   **If the true label is 1:** The equation becomes just $-\log(p)$. If $p = 0.99$, $-\log(0.99)$ is near 0. If $p = 0.01$, $-\log(0.01)$ explodes to 4.6.
*   **If the true label is 0:** The equation becomes just $-\log(1 - p)$.
</Callout>

For the entire dataset, you simply calculate the average Log Loss across all $N$ observations.

## Why use Log Loss instead of MSE?

If you are training a Logistic Regression model (which uses the Sigmoid function), you cannot use Mean Squared Error (MSE) as your loss function. 

Applying MSE to the output of a Sigmoid function creates a non-convex error surface (a landscape with many localized "valleys"). If you use Gradient Descent to minimize this, the algorithm will get stuck in a local valley and never find the true optimal weights. 

Log Loss, when applied to Logistic Regression, guarantees a **strictly convex** error surface (a single, smooth bowl shape). This guarantees that Gradient Descent will always find the global minimum.

## Multiclass Cross-Entropy

Log Loss naturally extends to multiclass problems (e.g., predicting if an image is a cat, dog, or bird). In this context, it is usually called **Categorical Cross-Entropy**. The formula compares the model's predicted probability distribution across all classes against the true one-hot encoded label, penalizing the model for not assigning 100% probability to the correct class.
