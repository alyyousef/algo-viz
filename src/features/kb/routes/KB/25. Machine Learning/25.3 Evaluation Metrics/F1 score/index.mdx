The **F1 Score** is a widely used metric for evaluating the performance of classification models, particularly when the dataset has a highly uneven class distribution (imbalanced classes).

It combines two competing metrics—**Precision** and **Recall**—into a single, easy-to-compare number.

## The Problem with the Arithmetic Mean

Why not just take the simple average (the arithmetic mean) of Precision and Recall?

Imagine a terrible model that predicts "Positive" for everything. 
*   Its Recall is 1.0 (it caught all positives).
*   Its Precision is 0.01 (it flagged almost everything incorrectly).
*   The arithmetic mean would be $(1.0 + 0.01) / 2 = 0.505$.

A score of 0.505 suggests the model is mediocre, but in reality, it is completely useless. The arithmetic mean masks terrible performance in one of the metrics.

## The Harmonic Mean (The F1 Formula)

The F1 Score uses the **Harmonic Mean** instead. The harmonic mean strongly punishes extreme values. If *either* Precision or Recall is very low, the F1 Score will also be very low.

$$\text{F1 Score} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

Using the previous example (Precision 0.01, Recall 1.0):
*   $\text{F1} = 2 \cdot \frac{(0.01 \cdot 1.0)}{(0.01 + 1.0)} = 2 \cdot \frac{0.01}{1.01} = 0.0198$

An F1 score of ~0.02 accurately reflects that the model is terrible. To get a high F1 score, a model must have *both* high precision and high recall.

<Callout icon="lightbulb" title="F-Beta Score">
The F1 score weights Precision and Recall equally. However, in some business cases, one is much more important than the other. The generalized **F-Beta Score** allows you to attach more weight to Recall ($\beta > 1$) or more weight to Precision ($\beta < 1$).
</Callout>

## Multiclass F1 Scores

If you have a multiclass classification problem (e.g., 5 different classes), calculating a single F1 score requires aggregating the F1 scores of each individual class. There are three common ways to do this:

1.  **Macro-F1:** Calculate the F1 score for each class separately, then take the unweighted average. This treats all classes equally, making it highly sensitive to the model's performance on rare minority classes.
2.  **Weighted-F1:** Calculate the F1 score for each class separately, then average them, weighting each class by its support (the number of true instances in the dataset). This is preferred if you want a metric that accounts for class imbalance overall.
3.  **Micro-F1:** Aggregate the global total of True Positives, False Positives, and False Negatives across all classes, then calculate Precision, Recall, and F1. (Note: For multiclass classification, Micro-F1 is mathematically identical to overall Accuracy).
