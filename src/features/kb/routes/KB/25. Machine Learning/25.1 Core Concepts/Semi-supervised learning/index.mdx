**Semi-Supervised Learning** sits precisely between Supervised Learning (where every data point has a label) and Unsupervised Learning (where no data points have labels).

It is used in scenarios where you have a massive dataset, but only a tiny fraction of it is labeled. 

## The Scenario

Imagine you are building an AI to detect a rare lung disease from X-Rays. 
- You have a database of 100,000 X-Rays from a hospital (Unlabeled Data).
- You paid a highly expensive doctor to sit down and manually label 500 of them as "Disease" or "Healthy" (Labeled Data).

If you only use Supervised Learning on the 500 labeled images, your model will overfit. If you only use Unsupervised Clustering on the 100,000 images, the model won't know which cluster represents the disease.

## How Semi-Supervised Learning Works

There are several techniques to leverage both datasets simultaneously.

### 1. Pseudo-Labeling (Self-Training)
1. Train a standard Supervised model on the 500 labeled X-Rays.
2. Use that model to predict the labels for the remaining 99,500 unlabeled X-Rays.
3. Take the predictions the model is *most confident* about (e.g., 99% probability of Healthy) and add them to the official Training Set as if they were ground truth. (These are "Pseudo-Labels").
4. Retrain the model on this newly expanded dataset. Repeat.

### 2. Graph-Based Label Propagation
1. Treat every image as a node in a massive graph.
2. Connect nodes that are mathematically similar to each other.
3. "Inject" the labels into the 500 known nodes.
4. Let the labels "flow" across the edges of the graph. If an unlabeled node is surrounded by 10 nodes that are all labeled "Disease", the unlabeled node is assigned the "Disease" label.

<Callout icon="warning" title="Confirmation Bias">
The biggest risk of Pseudo-Labeling is confirmation bias. If the initial model (trained on just 500 images) makes a confident mistake, it will label an unhealthy lung as "Healthy", add it to the training set, and learn to be *even more confident* about its mistake on the next iteration. 
</Callout>
