**Classification** is a form of Supervised Learning where the goal is to predict which discrete category (class) a new observation belongs to, based on a training dataset containing observations whose category membership is known.

Unlike Regression, which predicts a continuous number (like $245,000 for a house), Classification predicts a label (like "Spam" or "Not Spam").

## 1. Types of Classification

- **Binary Classification:** Only two possible outcomes. (e.g., Disease vs. No Disease, Fraud vs. Legitimate, Churn vs. Retain).
- **Multi-class Classification:** More than two possible outcomes, but each instance belongs to exactly one category. (e.g., Classifying an animal image as a Dog, Cat, OR Bird).
- **Multi-label Classification:** Each instance can be assigned multiple categories simultaneously. (e.g., A movie can be classified as both "Action" AND "Comedy").

## 3. Evaluation Metrics

Accuracy (total correct / total predictions) is often a terrible metric for classification, especially with **Imbalanced Data**. If 99% of credit card transactions are legitimate and 1% are fraud, a model that just hardcodes "Legitimate" for every transaction will be 99% accurate, but utterly useless.

Instead, we use the Confusion Matrix and its derivatives:

- **True Positives (TP):** Model predicted Fraud, and it was Fraud.
- **False Positives (FP):** Model predicted Fraud, but it was Legitimate (Type 1 Error).
- **False Negatives (FN):** Model predicted Legitimate, but it was Fraud (Type 2 Error).

From these, we calculate:
- **Precision:** Out of all the transactions the model flagged as Fraud, how many actually were? ($TP / (TP + FP)$)
- **Recall (Sensitivity):** Out of all the actual Fraud in the dataset, how many did the model catch? ($TP / (TP + FN)$)

<Callout icon="warning" title="The Precision-Recall Tradeoff">
You cannot maximize both simultaneously. If you want to catch 100% of terrorists boarding a plane (100% Recall), you will inevitably flag thousands of innocent grandmothers (Low Precision). If you only want to flag someone when you are 99.9% sure they are a terrorist (High Precision), you will inevitably let some slip through (Low Recall). The business context dictates which error is worse.
</Callout>
