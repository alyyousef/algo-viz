**Weakly-supervised learning** is an umbrella term for machine learning approaches that aim to construct predictive models by learning with weak supervision. In many real-world applications, acquiring large sets of fully and accurately labeled data (strong supervision) is prohibitively expensive or time-consuming. Weakly-supervised learning addresses this by utilizing labels that are imperfect.

## Types of Weak Supervision

There are three main types of weak supervision:

1.  **Incomplete Supervision (Semi-Supervised Learning):** Only a small subset of the training data has labels, while the vast majority is unlabeled.
2.  **Inexact Supervision (Multiple Instance Learning):** Labels are provided at a coarse-grained level rather than a fine-grained level. For example, an image is labeled as "contains a dog," but the exact bounding box (pixel-level location) of the dog is not provided.
3.  **Inaccurate Supervision:** The given labels are not always ground truth; they contain noise or errors. This often happens when using crowdsourcing, heuristics, or programmatic labeling (like Snorkel).

<Callout icon="lightbulb" title="Why use Weak Supervision?">
The primary motivation is **cost reduction**. Generating perfect labels requires human experts and significant time. Generating weak labels (e.g., using heuristic rules, knowledge bases, or non-expert annotators) is much cheaper and faster, allowing models to scale to massive datasets.
</Callout>

## Common Techniques

*   **Programmatic Labeling:** Writing heuristic rules, regular expressions, or using external knowledge bases to automatically assign noisy labels to unlabeled data. Tools like Snorkel unify multiple weak labeling functions to create probabilistic labels.
*   **Multiple Instance Learning (MIL):** The model learns from "bags" of instances. A bag is labeled positive if at least one instance inside it is positive, and negative if all instances are negative.
*   **Label Smoothing & Noise-Robust Loss Functions:** Modifying the loss function during training to prevent the model from over-trusting inaccurate labels.

## Summary

Weakly-supervised learning bridges the gap between the need for large labeled datasets in modern deep learning and the practical reality of limited annotation budgets. By embracing imperfect labels, these methods enable the training of powerful models on domains where strong supervision is infeasible.
