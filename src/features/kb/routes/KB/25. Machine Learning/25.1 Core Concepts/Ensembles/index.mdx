In Machine Learning, an **Ensemble** is the algorithmic equivalent of the "Wisdom of Crowds". Instead of relying on one massive, complex model to make a prediction, you train hundreds of simpler, slightly different models, and have them vote on the final answer.

Ensembles are the most dominant technique in traditional (tabular) machine learning. They consistently win Kaggle competitions when dealing with structured data (spreadsheets).

## 1. Bagging (Bootstrap Aggregating)

The goal of Bagging is to reduce **Variance** (prevent overfitting). 

**How it works:**
If you have a dataset of 1,000 rows, you create 100 new mini-datasets by sampling rows *with replacement* (meaning some rows are duplicated, some are left out). You then train 100 separate models (usually Decision Trees) in parallel, one on each mini-dataset.
When a new prediction is needed, all 100 trees vote (classification) or average their answers (regression).

**The King of Bagging: Random Forest**
A Random Forest goes one step further. Not only does every tree get a random subset of *rows*, but at every split, it only gets to look at a random subset of *columns*. This ensures all 100 trees are highly uncorrelated. 

## 2. Boosting

The goal of Boosting is to reduce **Bias** (prevent underfitting).

**How it works:**
Unlike Bagging where trees are built in parallel, Boosting builds trees **sequentially**. 
1. Tree #1 is trained on the data. It makes some correct predictions and some errors.
2. Tree #2 is trained specifically to fix the errors made by Tree #1. (The rows Tree #1 got wrong are given a higher "weight").
3. Tree #3 is trained to fix the errors of Tree #2.
4. This repeats hundreds of times. The final prediction is a weighted sum of all the trees.

**The Kings of Boosting: Gradient Boosted Trees (GBM, XGBoost, LightGBM)**
Instead of just increasing the weight of wrong answers, Gradient Boosting calculates the *Residuals* (the exact mathematical distance between the prediction and the true answer), and trains the next tree to directly predict the residual. 
Algorithms like **XGBoost** are heavily optimized versions of this process and are considered the industry standard for tabular data.

## 3. Stacking

Instead of using the same algorithm (like 100 Decision Trees), Stacking uses completely different algorithms.

**How it works:**
1. You train a Logistic Regression, a Random Forest, and a Support Vector Machine (the Base Learners) on the original dataset.
2. You take the predictions from those three models, and use them as the *inputs* for a fourth model (the Meta-Learner).
3. The Meta-Learner learns when to trust the Logistic Regression and when to trust the Random Forest.

<Callout icon="info" title="Why Ensembles Work">
Ensembles work for the same reason a diversified stock portfolio works. If one Decision Tree gets tricked by an outlier in the data and makes a wildly wrong prediction, the other 99 trees will overrule it. Because the trees are uncorrelated, their individual errors cancel each other out.
</Callout>
