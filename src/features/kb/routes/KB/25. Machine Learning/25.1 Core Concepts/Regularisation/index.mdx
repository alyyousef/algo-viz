**Regularization** is the primary weapon Data Scientists use to combat Overfitting (High Variance). 

When a model overfits, it has essentially memorized the training data by creating overly complex, hyper-specific rules (e.g., in a neural network, by assigning massive weight values to tiny, irrelevant features). Regularization forces the model to stay simple.

## 1. L1 and L2 Regularization (For Linear Models)

In standard Linear Regression, the algorithm tries to find the weights ($\beta$) that minimize the error (Loss). 
In Regularization, we change the Loss Function. We tell the algorithm: "Minimize the error, *but also minimize the size of your weights*."

### L1 Regularization (Lasso)
Adds the **Absolute Value** of the weights to the Loss Function.
$Loss = Error + \lambda \sum |\beta|$
- **The Effect:** L1 regularization is brutal. It will frequently shrink the weights of less important features to exactly 0.0. 
- **Use Case:** It acts as automatic Feature Selection. If you feed it 500 columns, Lasso might set 400 of them to exactly 0, giving you a highly interpretable model using only the 100 most important columns.

### L2 Regularization (Ridge)
Adds the **Squared Value** of the weights to the Loss Function.
$Loss = Error + \lambda \sum \beta^2$
- **The Effect:** L2 is gentler. It pushes all weights close to 0, but rarely makes them exactly 0.
- **Use Case:** Generally yields better predictive accuracy than L1 if all your features are at least somewhat relevant.

*(Note: **Elastic Net** is an algorithm that combines both L1 and L2).*

## 2. Dropout (For Neural Networks)

Neural networks are the ultimate overfitting machines. Because they have millions of parameters, they can easily memorize any dataset.

**Dropout** is an incredibly simple, elegant regularization technique for Deep Learning.
During training, at every single step, a random percentage (e.g., 20%) of the neurons in a layer are temporarily "turned off" (their weights are ignored). 

**Why it works:** It prevents "co-adaptation". If Neuron A knows that Neuron B is always going to catch its mistakes, Neuron A gets lazy. By randomly dropping Neuron B, Neuron A is forced to learn robust, independent representations of the data. 

## 3. Early Stopping (For Gradient Boosting / Neural Networks)

When training iterative models (models that get slightly better on every "epoch" or step), they eventually hit a point where the training error keeps dropping, but the validation error starts rising (the exact moment overfitting begins).

**Early Stopping** simply monitors the validation error. The moment the validation error stops improving for $N$ consecutive steps (called the "patience"), the training loop is aborted, and the model reverts to its best past state.

<Callout icon="lightbulb" title="The Lambda (λ) Parameter">
In L1 and L2 regularization, the parameter $\lambda$ (or sometimes $\alpha$) controls the strength of the penalty. If $\lambda = 0$, you have no regularization. If $\lambda$ is massive, the penalty is so strong that the model will just predict a flat horizontal line (Underfitting). Finding the perfect $\lambda$ requires Hyperparameter Optimization.
</Callout>
