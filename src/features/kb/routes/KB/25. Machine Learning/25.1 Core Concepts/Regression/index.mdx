**Regression** is a form of Supervised Learning where the goal is to predict a continuous, quantitative number (e.g., Temperature, Price, Revenue, Age) based on a set of input variables.

Unlike Classification, which predicts a discrete label ("Cat" or "Dog"), Regression predicts an infinite range of possible numbers (e.g., $45,291.54).

## 1. Linear Regression

The absolute foundation of predictive modeling, invented long before computers existed (by Legendre and Gauss in the early 1800s). 

It assumes that the relationship between the inputs ($X$) and the output ($Y$) is a straight line.
$$
Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + ... + \beta_nX_n
$$

The algorithm (usually using Ordinary Least Squares) calculates the $\beta$ coefficients (weights) that minimize the squared distance between the straight line and the actual data points.

**Pros:** 
- The most interpretable algorithm in existence. If $\beta_1$ (representing "Number of Bedrooms") is 50,000, you can literally tell the business: "Every additional bedroom adds exactly $50,000 to the house price."
**Cons:** 
- Highly prone to Underfitting. Very few things in the real world actually follow a perfectly straight line.

## 2. Polynomial Regression

A simple extension of Linear Regression. If the data is curved, you can add polynomial terms (like $X^2$ or $X^3$) to the equation.
$$
Y = \beta_0 + \beta_1X + \beta_2X^2
$$
The algorithm is still solved using the exact same linear math, but the resulting line drawn on the graph will curve to fit the data.

<Callout icon="warning" title="Runge's Phenomenon">
Be careful adding high-degree polynomials (e.g., $X^{15}$). The curve will violently zigzag to hit every single training data point perfectly, resulting in catastrophic Overfitting. This is a classic example of High Variance.
</Callout>
