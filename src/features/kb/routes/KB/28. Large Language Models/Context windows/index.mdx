The **Context Window** is the strict upper limit on the amount of text a Large Language Model (LLM) can process in a single interaction. 

It acts as the model's absolute short-term memory. If an LLM has a context window of 4,000 tokens, it can only "see" a document up to 4,000 tokens long. If you paste a 5,000-token document into the prompt, the model will literally delete the first 1,000 tokens from its memory before it begins reading. It will have absolutely no idea what the beginning of the document said.

## Why are Context Windows limited?

The context window limitation is a direct result of the core mathematics behind the **Transformer** architecture, specifically the **Self-Attention Mechanism**.

In a Transformer, every single word in a sentence must mathematically compare itself to *every other word* in the sentence to understand the context.
*   If you have 10 words, the computer performs $10^2$ (100) calculations.
*   If you have 1,000 words, the computer performs $1,000^2$ (1,000,000) calculations.
*   If you have 100,000 words, the computer performs **10 Billion** calculations.

This is known as **Quadratic Scaling ($O(N^2)$)**. As you increase the size of the text linearly, the amount of GPU RAM required to process it explodes exponentially. Historically, researchers capped context windows at 2,048 or 4,096 tokens simply because they ran out of physical VRAM on their supercomputers.

## The Evolution of Context Sizes

1.  **GPT-3 (2020):** 2,048 tokens (Roughly 1,500 words, or 3 pages of a book).
2.  **GPT-4 (Early 2023):** 8,000 tokens (Roughly 6,000 words, or 12 pages).
3.  **Claude 2 / GPT-4 Turbo (Late 2023):** 100,000 - 128,000 tokens (An entire 300-page novel).
4.  **Gemini 1.5 Pro (2024):** 1,000,000 - 2,000,000 tokens (Multiple massive books, or 1-2 hours of raw video footage).

## The "Needle in a Haystack" Problem

Just because an LLM accepts a massive 128K context window does not mean it can actually *remember* all 128K tokens accurately.

In 2023, researchers discovered the **"Lost in the Middle"** phenomenon. If you hide a specific fact (a "needle") in the exact middle of a 100,000-token document (the "haystack"), many LLMs completely fail to find it when asked. Models tend to heavily focus on the very beginning of a prompt and the very end of a prompt, while completely blurring or forgetting the information trapped in the middle.

<Callout icon="bolt" title="How did they fix Quadratic Scaling?">
How did models like Gemini jump from 8K to 2 Million tokens without requiring infinite RAM? Researchers developed advanced engineering techniques like **FlashAttention** (which rewrites the physical memory read/write logic on the GPU hardware level to avoid storing massive $N \times N$ matrices in slow memory) and **Ring Attention** (which mathematically splits the massive attention calculation across dozens of separate GPUs in a cluster).
</Callout>
