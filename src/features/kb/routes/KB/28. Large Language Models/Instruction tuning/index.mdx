<ConceptTemplate title="Instruction Tuning">

A raw, pre-trained base model (like the original GPT-3) is merely a mathematical autocomplete engine. If you prompt it with "Write a poem about the moon", it might respond with "Write a poem about the sun", because it is just continuing the pattern of a list of writing prompts.

**Instruction Tuning** (Supervised Fine-Tuning or SFT) is the process of training the model on a high-quality dataset of (Prompt, Response) pairs so it learns to follow instructions and act like a chatbot.

<Callout icon="success" title="The ChatGPT Magic">
  ChatGPT was not a new base model; it was GPT-3.5 that had undergone rigorous Instruction Tuning and Reinforcement Learning from Human Feedback (RLHF). This alignment process is what caused the explosive global adoption of AI.
</Callout>

## The Process

1. **Dataset Creation:** Humans write thousands of high-quality examples of prompts and the exact desired answers.
2. **Formatting:** The data is formatted using special chat templates (e.g., adding `<|user|>` and `<|assistant|>` tokens).
3. **Training:** The model is fine-tuned using standard Backpropagation to mathematically maximize the probability of the assistant\'s response given the user\'s prompt.
