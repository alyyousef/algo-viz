The **Encoder-Decoder Architecture** is the original layout of the Transformer (and earlier Recurrent Neural Networks) designed specifically for **Sequence-to-Sequence (Seq2Seq)** tasks.

A Seq2Seq task is any problem where you take a variable-length input (a sequence of words) and transform it into a variable-length output (a different sequence of words). 

*   *Example 1:* Translating a 10-word English sentence into an 8-word French sentence.
*   *Example 2:* Summarizing a 1,000-word news article into a 50-word paragraph.

## How the Architecture Works

As the name implies, the model is split into two distinct physical halves.

### 1. The Encoder (Reading)
The Encoder's only job is to read the input. 
It uses **Bidirectional Attention**. This means as it reads word #5, it can look backward at words 1-4, and look forward at words 6-10. By looking at the entire sentence simultaneously, it builds a massive, deep mathematical understanding of the context.
Once it finishes reading, it compresses all that understanding into a final array of numbers called the **Context Vector** (or Latent Representation).

### 2. The Decoder (Writing)
The Decoder's only job is to generate the output, one word at a time.
It uses **Masked Attention**. It starts with a blank slate, looks at the Encoder's Context Vector, and guesses the first French word. When guessing the second French word, it looks at the Context Vector *and* the first word it just generated. Because it is masked, it cannot look into the future. 

The two halves work together via **Cross-Attention**, where the Decoder constantly queries the Encoder to make sure it is staying true to the source text.

## Famous Encoder-Decoder Models

*   **T5 (Text-to-Text Transfer Transformer):** Built by Google, T5 is the most famous modern Encoder-Decoder model. It treats *every* NLP task as a Seq2Seq problem. If you want to classify a sentence as positive or negative, you don't use a classifier output layer; you literally ask T5 to read the text and generate the letters "p-o-s-i-t-i-v-e" on the Decoder side.
*   **BART:** Built by Facebook (Meta), it is highly optimized for complex abstractive text summarization.

<Callout icon="code-branch" title="The Industry Shift">
In the 2010s, almost all NLP was done using Encoder-Decoder models. Today, the industry has largely fractured. If you only need to *read* text (Search, Classification), you use an Encoder-Only model (BERT). If you only need to *generate* text (Chatbots, Code Generation), you use a Decoder-Only model (GPT). The full Encoder-Decoder architecture is now mostly reserved for highly specific translation or audio-transcription tasks.
</Callout>
