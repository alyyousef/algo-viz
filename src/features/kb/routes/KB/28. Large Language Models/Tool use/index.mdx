<ConceptTemplate title="Tool Use (Function Calling)">

By default, an LLM is a frozen mathematical brain trapped in a box. It cannot browse the internet, execute math reliably, or book a flight. 

**Tool Use** (or Function Calling) is the paradigm where the LLM is fine-tuned to recognize when it needs external information, and instead of generating text, it generates a structured JSON object requesting to run a specific tool.

<Callout icon="success" title="The Agentic Workflow">
  This is the foundation of AI Agents. The model outputs a tool call (e.g., `{"name": "get_weather", "args": {"location": "London"}}`). The backend intercepts this, executes the actual code, and feeds the result back into the LLM\'s context window so it can formulate a final answer.
</Callout>

## How Models Learn Tools

Models do not inherently know how to output perfect JSON. They must be explicitly fine-tuned.
