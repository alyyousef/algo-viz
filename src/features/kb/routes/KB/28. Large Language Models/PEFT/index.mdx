**PEFT (Parameter-Efficient Fine-Tuning)** is an umbrella term for a family of machine learning techniques designed to fine-tune massive AI models without needing to update every single weight in the network.

## The Problem with Full Fine-Tuning

When an open-source model like LLaMA-3 (70 Billion parameters) is released, it is a generalist. If a hospital wants to fine-tune it to exclusively output medical billing codes, they traditionally use **Full Fine-Tuning**.
This requires passing medical data through the network and using backpropagation to update all 70 Billion weights.

This causes three catastrophic bottlenecks:
1.  **Hardware:** You need roughly 6 massive NVIDIA A100 GPUs ($100,000+) to hold the optimizer states for 70 Billion parameters.
2.  **Catastrophic Forgetting:** If you aggressively update all 70B weights on medical data, the model often completely "forgets" how to do basic logic and math. It ruins the base model.
3.  **Storage:** The output of full fine-tuning is a brand new, massive 140GB file. If you have 10 different tasks, you need to store 1.4 Terabytes of models.

## How PEFT Solves It

The core philosophy of all PEFT techniques is the same: **Freeze the massive base model, and only train a tiny fraction of new parameters.**

By only training 1% (or less) of the parameters, PEFT allows you to fine-tune massive LLMs on a single $1,000 gaming GPU. Furthermore, because the original base model weights are frozen, the model retains 100% of its original general intelligence.

## The Major PEFT Techniques

While there are dozens of PEFT algorithms, the industry relies on a few key methods:

### 1. Adapters (The Original)
Invented in 2019, Adapters were the first major PEFT breakthrough. They work by physically inserting tiny, brand-new neural network layers directly in between the massive layers of the frozen base model. You only train the tiny new layers.
*Flaw:* Because you added physical layers to the architecture, the data has to travel further, causing the model to run slightly slower during inference.

### 2. Prompt Tuning / Prefix Tuning
Instead of changing the weights of the model, these techniques train "Soft Prompts." They mathematically inject a series of continuous, trainable vector embeddings directly into the user's prompt before it hits the LLM. 
*Flaw:* Very difficult to train and generally less accurate than altering the model's weights.

### 3. LoRA (Low-Rank Adaptation)
LoRA is the undisputed industry standard for PEFT today. Instead of adding new physical layers (like Adapters), LoRA injects tiny matrices *in parallel* to the frozen weights. Once training is complete, the tiny trained matrices are mathematically merged back into the frozen base weights.
*Advantage:* It is incredibly fast to train, highly accurate, and because the weights are merged, there is **zero inference latency**.

<Callout icon="bolt" title="QLoRA (Quantized LoRA)">
The ultimate evolution of PEFT is **QLoRA**. Introduced in 2023, QLoRA combines Quantization (compressing the frozen base model from 16-bit to 4-bit to save VRAM) with LoRA (training tiny parallel matrices). QLoRA allows a developer to fine-tune a massive 65-Billion parameter model on a single 48GB GPU, a feat that was considered physically impossible just a year prior.
</Callout>
