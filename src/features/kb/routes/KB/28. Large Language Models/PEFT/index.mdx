<ConceptTemplate title="Parameter-Efficient Fine-Tuning (PEFT)">

Fine-tuning a 70-Billion parameter model requires updating 70 billion weights. The optimizer states and gradients required for this process demand hundreds of gigabytes of VRAM, which is impossible on consumer GPUs.

Parameter-Efficient Fine-Tuning (PEFT) solves this by freezing the massive pretrained base model and mathematically injecting a tiny number of trainable parameters.

<Callout icon="tip" title="LoRA (Low-Rank Adaptation)">
  LoRA is the undisputed king of PEFT. It freezes the base model and injects trainable rank-decomposition matrices into the Transformer layers. It can reduce the number of trainable parameters by 10,000x and GPU memory requirements by 3x, allowing a 7B model to be fine-tuned on a single 16GB gaming GPU.
</Callout>
