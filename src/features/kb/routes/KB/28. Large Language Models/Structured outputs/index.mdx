When integrating LLMs into software pipelines, relying on the model to "hopefully" output valid JSON is a catastrophic point of failure. The model might add conversational filler (e.g., "Here is your JSON:") or hallucinate invalid keys, crashing the downstream application.

Structured Outputs enforce strict mathematical guarantees that the LLM\'s output will perfectly match a provided schema (like a Pydantic model or JSON Schema).


<Callout icon="tip" title="Constrained Decoding">


  Modern engines achieve 100% reliability using **Constrained Decoding**. During generation, the engine calculates the allowed next tokens based on a Finite State Machine derived from the JSON Schema. If the schema requires a boolean, the engine mathematically forces the probability of the word "true" or "false" to 100%, and masks out all other tokens in the vocabulary.


</Callout>
