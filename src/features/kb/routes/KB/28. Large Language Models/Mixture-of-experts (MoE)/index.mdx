Mixture-of-Experts (MoE) is an architectural pattern that replaces standard dense feedforward layers with multiple smaller "Expert" networks and a "Router" network.

During inference, instead of activating every single parameter in the model, the Router mathematically selects only the top 1 or 2 Experts to process a specific token. This allows you to build a 1-Trillion parameter model that runs as fast as a 100-Billion parameter model.


<Callout icon="info" title="The Open Source MoE Boom">


  Mistral\'s **Mixtral 8x7B** proved that open-source MoE models could rival GPT-3.5 while running on consumer hardware. It has 47 billion total parameters, but only uses 12 billion parameters during inference.


</Callout>
