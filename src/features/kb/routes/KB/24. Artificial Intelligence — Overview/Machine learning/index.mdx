**Machine Learning (ML)** is a subset of Artificial Intelligence. In classical software engineering, you write the rules, input the data, and the computer outputs the answers. 
In Machine Learning, you input the data and the answers, and the computer outputs the **rules**. 

## 1. The Core Paradigms

Machine Learning algorithms are generally split into three main categories based on how they interact with data.

### Supervised Learning
The model learns from labeled data. Every input vector ($X$) has a known, correct output ($Y$).
- **Classification:** The output is a discrete category. (e.g., Is this email "Spam" or "Not Spam"?). *Algorithms: Logistic Regression, Random Forest, Support Vector Machines (SVM).*
- **Regression:** The output is a continuous number. (e.g., Based on square footage and location, what is the price of this house?). *Algorithms: Linear Regression, XGBoost.*

### Unsupervised Learning
The model learns from unlabeled data. The input vector ($X$) has no known output. The algorithm's job is to find hidden structure.
- **Clustering:** Grouping similar data points together without knowing what the groups represent. (e.g., Customer segmentation). *Algorithms: K-Means, DBSCAN.*
- **Dimensionality Reduction:** Compressing high-dimensional data (e.g., a 10,000-pixel image) into fewer, more meaningful variables. *Algorithms: PCA, t-SNE.*

### Reinforcement Learning
The model learns by taking actions in an environment to maximize a cumulative reward. There is no training dataset of "correct answers"; the model discovers the optimal policy through trial and error.
- **Example:** Training a model to play chess, or teaching a robotic arm to walk. *Algorithms: Q-Learning, PPO.*

## 2. The Machine Learning Lifecycle

Training a model is often the easiest part of a Machine Learning project. The difficulty lies in the surrounding infrastructure (MLOps).

1. **Data Collection & Cleaning:** Models are highly sensitive to "Garbage In, Garbage Out". Handling missing values (Imputation) and removing outliers is critical.
2. **Feature Engineering:** (Critical in traditional ML, less so in Deep Learning). Transforming raw data into mathematical formats the model can easily use. For example, converting a `Date` column into a `Is_Weekend` boolean variable.
3. **Training & Validation:** The dataset is split. The model trains on 80% of the data, and is validated against the remaining 20% to ensure it actually learned patterns, rather than just memorizing the training data.
4. **Deployment & Inference:** The trained model (essentially a large mathematical equation saved in a file) is hosted on a server behind an API, receiving live user data and returning predictions.
5. **Monitoring (Drift):** Over time, real-world data changes (Data Drift). A model trained to predict housing prices in 2019 will perform terribly in 2024. The model must be continuously retrained.

## 3. The Bias-Variance Tradeoff

The fundamental tension in all of Machine Learning is balancing Bias and Variance.

- **Underfitting (High Bias):** The model is too simple to capture the underlying pattern. (e.g., trying to fit a straight line to a U-shaped scatter plot). It performs poorly on both training and test data.
- **Overfitting (High Variance):** The model is too complex. It perfectly memorizes the training data, including all the random noise, resulting in a jagged, hyper-specific curve. It achieves 100% accuracy on the training data, but performs terribly on new, unseen test data.

**The Goal:** A model that generalizes perfectly to data it has never seen before. We control overfitting using techniques called **Regularization** (e.g., L1/L2 penalties, Dropout).

<Callout icon="warning" title="Deep Learning vs. Traditional ML">
While Deep Learning (Neural Networks) gets all the media attention, traditional ML models like **XGBoost** (Gradient Boosted Trees) still dominate Kaggle competitions for structured, tabular data (spreadsheets). Deep Learning is only necessary for unstructured data (images, text, audio) where Feature Engineering is impossible.
</Callout>
