Before the Deep Learning boom of the 2010s, Artificial Intelligence was largely synonymous with **Search**. If you can formulate a problem as an initial state, a set of allowed actions, and a goal state, you can "solve" the problem by searching through a tree of all possible futures.

## 1. Uninformed vs. Informed Search

In an uninformed search, the AI knows nothing about the domain. It just blindly explores.
- **Breadth-First Search (BFS):** Explores all nodes at depth 1, then depth 2. Guarantees finding the shortest path, but requires massive memory.
- **Depth-First Search (DFS):** Dives down a single path until it hits a dead end, then backtracks. Uses very little memory, but might get stuck going down an infinitely long, wrong path.

**Informed Search (Heuristics)**
An informed search uses a **Heuristic** — a rule of thumb that estimates how close a state is to the goal.
- **A* (A-Star) Search:** The most famous informed search. It evaluates nodes by combining the exact cost taken to reach the node so far ($g(n)$) plus the estimated cost to reach the goal ($h(n)$). Used heavily in video game pathfinding and GPS navigation.

## 2. Adversarial Search (Game Playing)

When there is an opponent trying to stop you (like in Chess or Tic-Tac-Toe), standard search fails. You must assume the opponent will make the best possible move to ruin your plan.

- **Minimax Algorithm:** The AI calculates the entire tree of possible moves to the end of the game. It assigns a score (+1 for winning, -1 for losing). It then assumes that at every turn, it will pick the move that **Maximizes** the score, and the opponent will pick the move that **Minimizes** the score.
- **Alpha-Beta Pruning:** Minimax is too slow for complex games (Chess has more possible games than atoms in the universe). Alpha-Beta Pruning speeds it up by ignoring branches of the tree that it can mathematically prove are worse than a move it has already found.

## 3. The Limits of Search

Search algorithms dominated AI from the 1960s to the 1990s (culminating in IBM's Deep Blue beating Garry Kasparov at Chess in 1997 using Alpha-Beta Pruning). 

However, they failed at Go. The branching factor of Go is so large that Minimax tree search becomes computationally impossible. 

<Callout icon="info" title="The Synthesis: AlphaGo">
Google DeepMind solved Go in 2016 not by abandoning search, but by combining it with Deep Learning. **AlphaGo** used a Neural Network to evaluate the board (acting as an intuition/heuristic), which massively narrowed down the branches that a search algorithm (Monte Carlo Tree Search) needed to explore.
</Callout>
