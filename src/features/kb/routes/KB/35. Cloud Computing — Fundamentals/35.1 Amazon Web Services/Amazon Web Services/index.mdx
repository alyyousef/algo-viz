Amazon Web Services (AWS) is a massive cloud computing platform provided by Amazon. It provides a mix of infrastructure as a service (IaaS), platform as a service (PaaS) and packaged software as a service (SaaS) offerings.

<Callout icon="tip" title="Industry Dominance">
  AWS is the oldest and largest of the "Big 3" cloud providers, maintaining a massive market share and offering over 200 fully featured services from data centers globally.
</Callout>

## Core Compute Services

AWS compute services provide the fundamental processing power required to run applications in the cloud.
