**ViT** (Dosovitskiy et al., 2020) cuts an image into a grid of patches (e.g. 16×16), linearly embeds each patch, adds **position embeddings**, and runs a standard transformer encoder. A **CLS** token (or global average of patch tokens) becomes the image vector. No convolution is required — though hybrids still sneak convs in the stem.

## 1. Deep Dive and Mechanics

**Tokens.** A 224 image / 16 patch → 196 tokens. Attention is O(n²), so high-res detection needs windowed attention (Swin), pyramidal designs, or a conv neck.

**Inductive bias.** CNNs bake in locality. ViT learns locality from data. On ImageNet-scale data a vanilla ViT lags ResNet; on JFT-300M it wins. DeiT showed distillation and stronger aug can close the gap on ImageNet-1k.

**Variants.** Swin: shifted windows + hierarchy (good for dense tasks). MAE: reconstruct masked patches (excellent SSL). DINOv2: teacher-student features that transfer without labels. SAM's encoder is a heavy ViT.

**Position.** Learned 1-D embeddings do not naturally interpolate to a new resolution; many impls use 2-D interpolation of pos-embed at fine-tune.

<Callout icon="info" title="CLS vs GAP">
Original ViT uses a CLS token. Some modern recipes mean-pool patch tokens (like a conv GAP). Both work if you train that way. Do not mix a CLS-trained weight with GAP at inference.
</Callout>

## 2. Mathematical / Theoretical Foundation

Same transformer block as NLP: LN → MHSA → residual → LN → MLP. MHSA lets every patch talk to every other from layer 1 — a huge receptive field immediately, unlike a 3×3 stack. The cost is quadratic memory and weaker locality prior.

## 5. Interview Prep

**Q: Why patch 16 not patch 4?**
**A:** Finer patches → more tokens → quadratic blowup. Patch 4 is a different architecture (or a conv stem). 16 was the compute sweet spot for 224².

**Q: Is attention the reason ViT works?**
**A:** Scale + recipe matter as much. ConvNeXt got far with convs and ViT-like training. Attention helps long-range and flexible resolution more than it "replaces convolution" as a slogan.

**Q: How do you segment with ViT?**
**A:** Per-patch tokens as a coarse map, then upsample (SETR) or use a hierarchical backbone (Swin + UPerNet) or a mask decoder (SAM).

## 6. Production Use Cases

- **Foundation vision** (CLIP, DINOv2, MAE).
- **High-accuracy classify** when you can afford a ViT-L and 384 input.
- **Backbones** in DETR-like detectors.

<Callout icon="tip" title="Watch the pos-embed interpolate">
Serving 512² with weights trained at 224² without interpolating positions will look "mysteriously worse." It is not mysterious.
</Callout>
