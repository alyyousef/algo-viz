Modern CSS provides powerful tools to create fluid, hardware-accelerated motion without writing a single line of JavaScript.

## Transforms (Static Changes)
The `transform` property alters the visual appearance of an element without affecting the document flow (it won't push other elements out of the way).
- `translate(x, y)`: Moves the element.
- `scale(n)`: Enlarges or shrinks.
- `rotate(deg)`: Spins the element.

## Transitions (A to B)
`transition` is used to smoothly interpolate between states (like a hover effect).

```css
.btn {
  background-color: blue;
  transform: scale(1);
  transition: all 0.3s ease-in-out;
}

.btn:hover {
  background-color: red;
  transform: scale(1.1);
}
```

## Keyframe Animations (Complex Sequences)
For continuous animations or complex multi-step sequences, you use `@keyframes`.

```css
@keyframes pulse {
  0% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.5); opacity: 0.5; }
  100% { transform: scale(1); opacity: 1; }
}

.loading-dot {
  animation: pulse 2s infinite linear;
}
```

<Callout icon="warning" title="Performance & The GPU">
You should only ever animate `transform` and `opacity`. Animating properties like `width`, `margin`, or `box-shadow` forces the browser to recalculate the entire page layout on every single frame, causing severe lag on mobile devices. Transforms are offloaded directly to the device's GPU for silky smooth 60FPS motion.
</Callout>
