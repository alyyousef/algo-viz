Before **Flexbox** (introduced around 2012), developers relied on massive hacks—like floats, clearfixes, and absolute positioning—just to align elements horizontally. Flexbox revolutionized CSS by providing a robust, one-dimensional layout engine.

## The Main Axis vs. Cross Axis

Flexbox is all about direction. When you set `display: flex;` on a container, you define an axis.
- **Main Axis**: Controlled by `justify-content` (aligns items along the row or column).
- **Cross Axis**: Controlled by `align-items` (aligns items perpendicular to the main axis).

## Centering a Div

The holy grail of CSS used to take 10 lines of complex code. With Flexbox, centering a div horizontally and vertically takes three lines:

```css
.container {
  display: flex;
  justify-content: center; /* Center horizontally */
  align-items: center;     /* Center vertically */
}
```

## Flex Items (The Children)
While the container dictates the overall layout, the children can dictate their own behavior:
- `flex-grow`: How much of the leftover space this item should consume.
- `flex-shrink`: How much this item should shrink if there isn't enough space.
- `flex-basis`: The default size before growing or shrinking.

<Callout icon="tip" title="The flex shorthand">
You'll often see `flex: 1;` on a child element. This is shorthand for `flex-grow: 1; flex-shrink: 1; flex-basis: 0%;`. It tells the item to fill all available space equally.
</Callout>
