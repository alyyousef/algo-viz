**BASIC** (Beginner's All-purpose Symbolic Instruction Code) was created in 1964 by John Kemeny and Thomas Kurtz at Dartmouth College. 

Before BASIC, using a computer meant writing cryptic Assembly or Fortran code on punched cards, handing them to a technician in a white lab coat, and waiting hours for the mainframe to process them. BASIC revolutionized the world by introducing the concept of Interactive Time-Sharing. It was an incredibly simple, English-like language that could be typed directly into a terminal and executed instantly. In the late 1970s and 1980s, when personal computers (like the Apple II and Commodore 64) were invented, BASIC was baked directly into their ROMs. It was the language that taught the world how to code.

## 1. Deep Dive & Mechanics

The defining mechanical feature of classic BASIC is the **Line Number**.

In modern languages, code executes sequentially from top to bottom, organized by functions. In early BASIC, every single line of code had to be manually prefixed with an integer line number (e.g., `10`, `20`, `30`). The interpreter executed the code in numerical order. 

To create loops, branching, or conditional logic, developers used the infamous **GOTO statement**. If a condition was met, the program would unconditionally jump to a different line number (e.g., `IF X = 5 THEN GOTO 100`). This resulted in "Spaghetti Code"—code so deeply intertwined with jumps back and forth that tracing the logical flow became a mathematical nightmare.

## 2. Mathematical / Theoretical Foundation

Early BASIC was an **Unstructured, Interpreted Language**.

Unlike ALGOL or Pascal, which were built on the mathematical foundation of the Structured Program Theorem (using encapsulated blocks and lexical scoping), early BASIC possessed no blocks, no local variables, and no true functions. Every variable was global. If you changed the variable `X` on line 100, it permanently altered `X` for the rest of the program.

While this lack of mathematical rigor made it incredibly easy for beginners to learn, computer science academics despised it. The famous computer scientist Edsger W. Dijkstra famously stated: *"It is practically impossible to teach good programming to students that have had a prior exposure to BASIC: as potential programmers they are mentally mutilated beyond hope of regeneration."*

## 3. Real-World Implementation

Here is an example demonstrating the classic Dartmouth/Microcomputer BASIC syntax. Notice the strict use of line numbers, global variables, and the `GOTO` statement.

```basic
10 REM 1. This is a comment (REMark)
20 REM A classic Number Guessing Game

30 PRINT "WELCOME TO THE GUESSING GAME!"
40 LET S = 7  REM 2. The secret number (Variables are global)

50 REM 3. The main loop entry point
60 PRINT "GUESS A NUMBER BETWEEN 1 AND 10:"
70 INPUT G  REM 4. Halts execution and waits for user input

80 REM 5. Conditional logic with GOTO branching
90 IF G = S THEN GOTO 140
100 IF G < S THEN PRINT "TOO LOW!"
110 IF G > S THEN PRINT "TOO HIGH!"

120 REM 6. Unconditional jump to loop back to the input
130 GOTO 60

140 REM 7. Success State
150 PRINT "YOU GUESSED IT! CONGRATULATIONS!"
160 END
```

## 5. Interview Prep

**Q: Why did old BASIC require Line Numbers?**
**A:** In the 1970s, computers did not have graphical text editors or mice. If you made a mistake on line 20, you couldn't just click on it to fix it. You had to type `20 PRINT "FIXED"` into the terminal, and the interpreter would mathematically overwrite whatever was previously stored at line 20 in memory. Line numbers were the only way to navigate and edit code on a primitive command-line interface.

**Q: What is "Spaghetti Code"?**
**A:** Spaghetti Code refers to unstructured programs that heavily rely on `GOTO` statements to jump around the codebase. Because the execution flow constantly jumps between arbitrary line numbers without enclosed blocks or functions, tracing the logic becomes tangled and impossible to follow, resembling a bowl of spaghetti.

**Q: Did Bill Gates write BASIC?**
**A:** Bill Gates and Paul Allen did not invent the BASIC language, but they wrote Altair BASIC (an interpreter for the Altair 8800 microcomputer) in 1975. This was the foundational software product that launched Microsoft, allowing early computer hobbyists to actually program their machines.

## 6. Historical & Production Impact

Classic BASIC is dead in modern production, but its impact on the industry is unparalleled:
- **The Microcomputer Revolution:** The Apple II, Commodore 64, and ZX Spectrum booted directly into a BASIC prompt. Millions of teenagers in the 1980s learned to code by copying BASIC games out of magazines line-by-line.
- **The Visual Basic Era:** Microsoft took the approachable syntax of BASIC, stripped out the Line Numbers, added Object-Based concepts, and created Visual Basic in the 1990s, dominating Windows application development for a decade.
- **Modern Survivors (VBA/VB.NET):** The syntax survives today in VBA (Visual Basic for Applications), which automates Microsoft Office macros, and VB.NET, which remains a fully supported (though sunsetting) language on the modern .NET Framework.

<Callout icon="info" title="The 10-Step Convention">
You might notice that BASIC programs rarely used lines 1, 2, 3, 4. They used 10, 20, 30. This was a deliberate hack by developers. Because you couldn't easily insert a line between 1 and 2, numbering by 10s left mathematical "gaps." If you forgot a step, you could retroactively insert line `15` without having to manually renumber the rest of the program!
</Callout>
