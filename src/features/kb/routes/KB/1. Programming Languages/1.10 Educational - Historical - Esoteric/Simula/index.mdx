Developed in the 1960s at the Norwegian Computing Center by Ole-Johan Dahl and Kristen Nygaard, **Simula** (specifically Simula 67) is the patriarch of modern software engineering.

Before Simula, code was strictly procedural. Programs were just a sequence of instructions executing top-to-bottom, operating on global data. 

Dahl and Nygaard were tasked with writing software to simulate complex, real-world systems (like ships moving through a port, or customers queuing at a bank). They realized that procedural code was a terrible way to model the real world. They needed a way to mathematically bundle a "Ship's" data (speed, location) and its behavior (accelerate, turn) into a single, cohesive unit. 

To solve this, **they invented the Class.**

## 1. Deep Dive & Mechanics

Simula was built as a direct superset of **ALGOL 60**. It took ALGOL's block structures and added the concepts that define the entire modern software industry:

1. **Classes and Objects:** Simula was the first language to define a `Class` as a template, and an `Object` as a specific instance of that template in memory.
2. **Inheritance:** Simula invented the concept of Subclasses. You could define a `Vehicle` class, and then define a `Car` class that mathematically inherited all the properties of `Vehicle`.
3. **Virtual Procedures:** Simula introduced what C++ and Java call Polymorphism. A base class could define a procedure, and a subclass could override it.
4. **Garbage Collection:** Because Objects were instantiated dynamically in memory, Simula featured an automatic garbage collector to clean them up.

## 2. Mathematical / Theoretical Foundation

The mathematical breakthrough of Simula was **Data Encapsulation and State Preservation**.

In procedural languages like C or Pascal, a function executes, uses local variables, and when the function ends, those variables are mathematically destroyed (popped off the stack). 

In Simula, a Class was essentially a procedure that *did not die* when it finished executing. The variables inside the Class (its state) were preserved in the Heap, and the internal functions (methods) could be called repeatedly by other parts of the program to mutate that preserved state. This shifted the entire paradigm of computing from "Action-Oriented" to "State-Oriented".

## 3. Real-World Implementation

Here is an example demonstrating the actual syntax of Simula 67. If you know Java or C++, this syntax from 1967 should look hauntingly familiar, because Java and C++ directly stole these concepts from Simula.

```simula
! 1. This is a comment in Simula. ;

! 2. Defining a Base Class ;
Class Vehicle(Weight, Speed);
  Real Weight, Speed;
Begin
  ! This is a method (procedure) inside the class ;
  Procedure Accelerate(Amount); Real Amount;
  Begin
    Speed := Speed + Amount;
  End;
End;

! 3. Inheritance (Subclassing) ;
! 'Car' inherits from 'Vehicle' ;
Vehicle Class Car(NumDoors);
  Integer NumDoors;
Begin
  Procedure Honk;
  Begin
    OutText("Beep! Beep!");
    OutImage; ! OutImage pushes the text to the console ;
  End;
End;

! 4. Main Program Execution ;
Begin
  ! 5. Reference Variables (Pointers) ;
  Ref(Car) MyVolvo;
  
  ! 6. Object Instantiation (The 'new' keyword was invented here!) ;
  MyVolvo :- New Car(1500.0, 0.0, 4);
  
  ! 7. Calling Methods on the Object ;
  MyVolvo.Accelerate(50.0);
  MyVolvo.Honk;
End;
```

## 5. Interview Prep

**Q: What programming paradigm did Simula invent?**
**A:** Object-Oriented Programming (OOP). Simula 67 introduced the fundamental concepts of Classes, Objects, Inheritance, Virtual Procedures (Polymorphism), and dynamic object instantiation using the `new` keyword.

**Q: Why was Simula created?**
**A:** As the name suggests, it was created for **Simula**tions. The creators were trying to model complex real-world systems (like toll booths or maritime shipping). They realized that modeling real-world entities required a programming architecture that grouped an entity's data and its behaviors together into a single, cohesive unit (an Object).

**Q: How did Simula influence C++?**
**A:** Bjarne Stroustrup, the creator of C++, actively used Simula during his PhD research in the 1970s. He loved Simula's object-oriented architecture for organizing complex code, but he needed the raw, bare-metal speed of C. He explicitly designed C++ (originally called "C with Classes") to map Simula's OOP concepts directly onto the fast, low-level C compiler.

## 6. Historical Impact & Legacy

Nobody writes production code in Simula today. However, its historical impact makes it one of the three most important programming languages ever created (alongside C and Lisp).
- **The Inspiration for Smalltalk:** Alan Kay saw Simula and took its concept of Objects to the extreme, creating Smalltalk, which coined the actual phrase "Object-Oriented Programming."
- **The DNA of the Modern Enterprise:** Every single class you write in Java, C#, C++, Python, or TypeScript is a direct mathematical descendant of the syntax and theoretical architecture finalized by Kristen Nygaard and Ole-Johan Dahl in Oslo in 1967. 

<Callout icon="info" title="The Turing Award">
In 2001, Dahl and Nygaard were jointly awarded the Turing Award (the Nobel Prize of Computer Science) specifically for the creation of Simula 67 and the invention of Object-Oriented Programming, acknowledging that their creation completely reshaped the software industry.
</Callout>
