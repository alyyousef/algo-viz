**Declarative Programming** is one of the two primary umbrellas of computer science (the other being Imperative). 

*   **Imperative (The "How"):** You give the computer step-by-step instructions. *"Go to the fridge, open the door, grab the milk, pour it in the glass."* (C, Java, Python).
*   **Declarative (The "What"):** You describe the desired end state and let the underlying engine figure out the steps. *"I want a glass of milk."* (SQL, HTML, CSS).

As software engineering has matured, the entire industry has steadily shifted away from Imperative and toward Declarative code, because it is significantly easier to read, test, and scale.

## Examples of the Declarative Paradigm

### 1. Database Queries (SQL)
SQL is the most famous declarative language in the world. 
If you want to find all users older than 18, you do not write a `for` loop to iterate over the hard drive sectors. You simply declare:
`SELECT * FROM users WHERE age > 18;`
The database engine's query optimizer looks at this declaration and internally figures out the fastest physical algorithms (B-Tree lookups, hash joins) to fetch that data.

### 2. User Interfaces (React / SwiftUI)
Historically, building a UI was Imperative (e.g., jQuery). You had to write step-by-step code: *"Find the button by ID, change its color to red, create a new div, append it to the body."*

Modern frameworks (React, Vue, SwiftUI, Jetpack Compose) are entirely Declarative. You simply declare the state:
*"If `isError` is true, the button is red. Otherwise, it is blue."*
When the `isError` variable changes, the React engine automatically figures out the exact DOM manipulations required to make the screen match your declaration. 

### 3. Infrastructure as Code (Terraform / Kubernetes)
If a DevOps engineer needs 5 servers running in AWS, they do not write a Python script that explicitly calls the AWS API 5 times (Imperative). 
They write a declarative YAML file stating: `replicas: 5`. 
If a server crashes, the Kubernetes engine notices that reality (`4 servers`) no longer matches the declaration (`5 servers`), and it automatically spins up a new server to fix the discrepancy.

<Callout icon="code-compare" title="Functional Programming is Declarative">
**Functional Programming** (Haskell, Clojure) is a major subset of Declarative programming. Instead of writing `for` loops (imperative), you declare mathematical transformations using `map()`, `filter()`, and `reduce()`. You are declaring the shape of the data transformation, rather than explicitly managing the loop counters.
</Callout>
