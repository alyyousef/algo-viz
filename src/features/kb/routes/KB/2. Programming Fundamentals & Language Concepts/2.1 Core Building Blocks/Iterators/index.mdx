An Iterator is a mathematical abstraction that allows a developer to traverse a container (like a List or a Tree) without needing to know exactly how that container physically stores its data in memory.

## 1. The Mathematical Interface
In Java or C++, if you have an Array, you can mathematically traverse it using an integer index: `array[i]`.
However, if you have a Linked List or a Binary Tree, `tree[i]` is mathematically invalid because the memory is not contiguous.
An Iterator provides a universal mathematical interface (usually just a `next()` method and a `hasNext()` boolean). The complex logic of chasing memory pointers through a massive Binary Tree is completely hidden inside the Iterator object. The developer simply writes `while(it.hasNext()) { process(it.next()); }`, and it works flawlessly on any data structure.

## 2. For-Each Loops
Modern languages provide `for-each` loops (e.g., `for (String name : names)`).
This syntax is actually "Syntactic Sugar." The compiler mathematically translates the `for-each` loop into an Iterator under the hood. It silently instantiates the Iterator object, calls `hasNext()`, extracts the value with `next()`, and binds it to your local variable, mathematically guaranteeing that you will never accidentally cause an "Index Out of Bounds" memory error.
