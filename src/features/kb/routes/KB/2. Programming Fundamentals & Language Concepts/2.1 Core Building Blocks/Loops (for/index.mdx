A `for` loop is the mathematical standard for Definite Iteration—used when you know exactly how many times a block of code should execute.

## 1. The Three-Part Structure
In C-style languages, a `for` loop is mathematically broken into three distinct execution phases: `for (initialization; condition; increment)`.
1. **Initialization** (`int i = 0`): Mathematically executes exactly once before the loop starts, allocating the index variable on the stack.
2. **Condition** (`i &lt; 10`): Mathematically evaluates before every single iteration. If false, the loop instantly terminates.
3. **Increment** (`i++`): Mathematically executes at the very end of the loop block, just before jumping back to the condition.

## 2. Array Traversal and Cache Hits
The `for` loop is mathematically inseparable from Arrays.
Because an array is a contiguous block of memory, a `for` loop incrementing an integer index (`i++`) mathematically accesses RAM in a perfectly predictable, linear pattern. Modern CPUs detect this mathematical pattern instantly and use **Hardware Prefetching** to load the next 64 bytes of the array into the L1 Cache before the loop even asks for it, making standard `for` loops the fastest possible way to process data on bare metal.
